## What's Changed

### 🏞️ Highlights

- Steer Agent runs in progress or queue the next message
- Agents can pause to ask questions or request tool approval, then resume
- Redesigned Agent Builder with a unified Tools marketplace and background tool calls
- Stateful Code Interpreter sessions with reusable conversation workspaces
- Agent-managed memory with optional per-agent isolation
- Continue shared conversations as personal copies
- Opt-in Langfuse fanout for central and tenant tracing
- Provider updates: GPT-5.6, Claude Sonnet 5, Gemini 3.6 Flash, and Gemini 3.5 Flash-Lite
