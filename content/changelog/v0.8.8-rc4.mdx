## What's Changed

### 🏞️ Highlights

- Public Agents API with OpenAPI spec and docs
- Conversation-isolated attached workspaces with repository instructions
- Expanded Trace Viewer with steps, roles, previews, and cost
- Same-run Skill authoring and execution
- System-event turns and single-row live activity
- Faster streaming Markdown, model search, and Agent messages
- Stronger MCP authentication and per-request headers
