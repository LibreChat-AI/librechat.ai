<Callout type="info" title="只想开始聊天？">

立即在项目的免费公共演示版 [chat.librechat.ai](https://chat.librechat.ai) 上试用 LibreChat：在那里创建一个账户并开始对话。该演示版仅供评估使用，因此不适合存放私人数据或任何您需要保留的内容（[服务条款](/demo/terms)，[隐私政策](/demo/privacy)）。

若要部署您自己的实例，请通过 [快速入门](/docs/quick_start) 安装 LibreChat（使用 Docker 大约需要五分钟），然后按照 [您的第一次对话](/docs/quick_start/first_chat) 创建账户、添加模型 API 密钥并发送您的第一条消息。

</Callout>

<DocsHub />

<Callout type="info" title="正在寻找桌面安装程序？">

LibreChat 是一个自托管的 Web 应用程序，而非原生的 Windows 应用或 Linux AppImage。在 Windows 上，请使用 [Docker Desktop](/docs/local/docker) 进行最简单的本地设置。对于 Linux 桌面或服务器，请使用 [Docker](/docs/local/docker)、[npm](/docs/local/npm) 或参考[远程托管指南](/docs/remote)。

</Callout>
