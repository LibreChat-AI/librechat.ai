<Callout type="info" title="Chcesz po prostu zacząć czatować?">

Wypróbuj LibreChat już teraz w darmowej publicznej wersji demonstracyjnej projektu pod adresem [chat.librechat.ai](https://chat.librechat.ai): utwórz tam konto i rozpocznij rozmowę. Wersja demonstracyjna służy wyłącznie do celów ewaluacyjnych, więc nie jest to miejsce na prywatne dane ani cokolwiek, co musisz zachować ([warunki](/demo/terms), [prywatność](/demo/privacy)).

Aby uruchomić własną instancję, zainstaluj LibreChat korzystając z [Quick Start](/docs/quick_start) (zajmuje to około pięciu minut z Docker), a następnie postępuj zgodnie z [Your First Chat](/docs/quick_start/first_chat), aby utworzyć konto, dodać klucz API modelu i wysłać swoją pierwszą wiadomość.

</Callout>

<Callout type="info" title="Szukasz instalatora na pulpit?">

LibreChat to samodzielnie hostowana aplikacja internetowa, a nie natywna aplikacja dla systemu Windows czy AppImage dla systemu Linux. W systemie Windows użyj [Docker Desktop](/docs/local/docker), aby uzyskać najprostszą konfigurację lokalną. W przypadku komputerów stacjonarnych lub serwerów z systemem Linux użyj [Docker](/docs/local/docker), [npm](/docs/local/npm) lub [przewodnika po zdalnym hostingu](/docs/remote).

</Callout>
