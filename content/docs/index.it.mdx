<Callout type="info" title="Vuoi solo iniziare a chattare?">

Prova subito LibreChat sulla demo pubblica gratuita del progetto su [chat.librechat.ai](https://chat.librechat.ai): crea un account e avvia una conversazione. La demo è solo per scopi di valutazione, quindi non è il posto adatto per dati privati o qualsiasi cosa tu debba conservare ([termini](/demo/terms), [privacy](/demo/privacy)).

Per una tua istanza, installa LibreChat con la [Guida rapida](/docs/quick_start) (circa cinque minuti con Docker), quindi segui [La tua prima chat](/docs/quick_start/first_chat) per creare il tuo account, aggiungere una chiave API del modello e inviare il tuo primo messaggio.

</Callout>

<Callout type="info" title="Cerchi un programma di installazione desktop?">

LibreChat è un'applicazione web self-hosted, non un'app nativa Windows o un AppImage Linux. Su Windows, utilizza [Docker Desktop](/docs/local/docker) per la configurazione locale più semplice. Per desktop o server Linux, utilizza [Docker](/docs/local/docker), [npm](/docs/local/npm) o una [guida all'hosting remoto](/docs/remote).

</Callout>
