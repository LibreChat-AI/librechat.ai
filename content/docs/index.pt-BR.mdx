<Callout type="info" title="Quer apenas começar a conversar?">

Experimente o LibreChat agora mesmo na demonstração pública gratuita do projeto em [chat.librechat.ai](https://chat.librechat.ai): crie uma conta lá e inicie uma conversa. A demonstração é apenas para avaliação, portanto, não é o local para dados privados ou qualquer coisa que você precise manter ([termos](/demo/terms), [privacidade](/demo/privacy)).

Para sua própria instância, instale o LibreChat com o [Quick Start](/docs/quick_start) (cerca de cinco minutos com Docker), então siga [Your First Chat](/docs/quick_start/first_chat) para criar sua conta, adicionar uma chave de API de modelo e enviar sua primeira mensagem.

</Callout>

<Callout type="info" title="Procurando por um instalador para desktop?">

LibreChat é uma aplicação web auto-hospedada, não um aplicativo nativo do Windows ou AppImage do Linux. No Windows, use o [Docker Desktop](/docs/local/docker) para a configuração local mais simples. Para desktops ou servidores Linux, use [Docker](/docs/local/docker), [npm](/docs/local/npm) ou um [guia de hospedagem remota](/docs/remote).

</Callout>
