<Callout type="info" title="Vous voulez juste commencer à discuter ?">

Essayez LibreChat dès maintenant sur la démo publique gratuite du projet à l'adresse [chat.librechat.ai](https://chat.librechat.ai) : créez-y un compte et commencez une conversation. La démo est uniquement destinée à l'évaluation, ce n'est donc pas l'endroit pour des données privées ou tout ce que vous devez conserver ([conditions](/demo/terms), [confidentialité](/demo/privacy)).

Pour votre propre instance, installez LibreChat avec le [Quick Start](/docs/quick_start) (environ cinq minutes avec Docker), puis suivez [Your First Chat](/docs/quick_start/first_chat) pour créer votre compte, ajouter une clé API de modèle et envoyer votre premier message.

</Callout>

<Callout type="info" title="Vous cherchez un installateur pour ordinateur ?">

LibreChat est une application web auto-hébergée, et non une application Windows native ou une AppImage Linux. Sous Windows, utilisez [Docker Desktop](/docs/local/docker) pour une installation locale simplifiée. Pour les ordinateurs de bureau ou serveurs Linux, utilisez [Docker](/docs/local/docker), [npm](/docs/local/npm), ou un [guide d'hébergement distant](/docs/remote).

</Callout>
