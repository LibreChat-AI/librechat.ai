<Callout type="info" title="Mencari penginstal desktop?">

LibreChat adalah aplikasi web yang di-host sendiri (self-hosted), bukan aplikasi Windows asli atau AppImage Linux. Tidak ada penginstal untuk diunduh dan dijalankan: Anda memulai server menggunakan salah satu opsi di atas, lalu gunakan LibreChat di browser Anda.

Di Windows, [Docker Desktop](/docs/local/docker) adalah cara termudah.

</Callout>
