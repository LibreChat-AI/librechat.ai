<Callout type="info" title="Apakah ada aplikasi untuk Windows atau macOS?">

Tidak. LibreChat adalah aplikasi web yang di-host sendiri (self-hosted), jadi tidak ada `.exe`, `.dmg`, atau AppImage untuk diunduh: Anda menginstalnya sendiri menggunakan salah satu metode di bawah ini, lalu menggunakannya di browser Anda. Docker dan npm menjalankannya di mesin Anda sendiri di Windows, macOS, atau Linux dan menyajikannya di [http://localhost:3080](http://localhost:3080); di Windows, [Docker Desktop](/docs/local/docker) adalah titik awal yang paling sederhana. Helm chart digunakan untuk men-deploy ke klaster Kubernetes, dan diakses melalui jaringan klaster Anda.

</Callout>

<Callout type="info" title="Mencari penginstal desktop?">

LibreChat adalah aplikasi web yang di-host sendiri (self-hosted), bukan aplikasi Windows asli atau AppImage Linux. Tidak ada penginstal untuk diunduh dan dijalankan: Anda memulai server menggunakan salah satu opsi di atas, lalu gunakan LibreChat di browser Anda.

Di Windows, [Docker Desktop](/docs/local/docker) adalah cara termudah.

</Callout>
