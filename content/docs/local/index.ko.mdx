<Callout type="info" title="데스크톱 설치 프로그램을 찾으시나요?">

LibreChat은 자체 호스팅 웹 애플리케이션이며, 네이티브 Windows 앱이나 Linux AppImage가 아닙니다. 다운로드하여 실행할 설치 프로그램은 없으며, 위의 옵션 중 하나를 사용하여 서버를 시작한 다음 브라우저에서 LibreChat을 사용하면 됩니다.

Windows에서는 [Docker Desktop](/docs/local/docker)을 사용하는 것이 가장 간단한 방법입니다.

</Callout>
