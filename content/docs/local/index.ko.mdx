<Callout type="info" title="Windows 또는 macOS용 앱이 있나요?">

아니요. LibreChat은 자체 호스팅되는 웹 애플리케이션이므로 다운로드할 `.exe`, `.dmg` 또는 AppImage가 없습니다. 아래 방법 중 하나를 사용하여 직접 설치한 다음 브라우저에서 사용하면 됩니다. Docker와 npm은 Windows, macOS 또는 Linux의 사용자 기기에서 이를 실행하며 [http://localhost:3080](http://localhost:3080)에서 서비스합니다. Windows의 경우 [Docker Desktop](/docs/local/docker)이 가장 간편한 시작점입니다. Helm 차트는 대신 Kubernetes 클러스터에 배포되며, 클러스터의 네트워킹을 통해 접속할 수 있습니다.

</Callout>

<Callout type="info" title="데스크톱 설치 프로그램을 찾으시나요?">

LibreChat은 자체 호스팅 웹 애플리케이션이며, 네이티브 Windows 앱이나 Linux AppImage가 아닙니다. 다운로드하여 실행할 설치 프로그램은 없으며, 위의 옵션 중 하나를 사용하여 서버를 시작한 다음 브라우저에서 LibreChat을 사용하면 됩니다.

Windows에서는 [Docker Desktop](/docs/local/docker)을 사용하는 것이 가장 간단한 방법입니다.

</Callout>
