<Callout type="info" title="Gibt es eine Windows- oder macOS-App?">

Nein. LibreChat ist eine selbst gehostete Webanwendung, daher gibt es keine `.exe`, `.dmg` oder AppImage zum Herunterladen: Sie installieren es selbst mit einer der unten aufgeführten Methoden und verwenden es dann in Ihrem Browser. Docker und npm führen es auf Ihrem eigenen Rechner unter Windows, macOS oder Linux aus und stellen es unter [http://localhost:3080](http://localhost:3080) bereit; unter Windows ist [Docker Desktop](/docs/local/docker) der einfachste Ausgangspunkt. Das Helm-Chart wird stattdessen in einem Kubernetes-Cluster bereitgestellt und über das Netzwerk Ihres Clusters erreicht.

</Callout>

<Callout type="info" title="Suchen Sie nach einem Desktop-Installer?">

LibreChat ist eine selbst gehostete Webanwendung, keine native Windows-App oder Linux AppImage. Es gibt keinen Installer zum Herunterladen und Ausführen: Sie starten den Server mit einer der oben genannten Optionen und verwenden LibreChat anschließend in Ihrem Browser.

Unter Windows ist [Docker Desktop](/docs/local/docker) der einfachste Weg.

</Callout>
