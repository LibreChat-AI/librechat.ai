<Callout type="info" title="Suchen Sie nach einem Desktop-Installer?">

LibreChat ist eine selbst gehostete Webanwendung, keine native Windows-App oder Linux AppImage. Es gibt keinen Installer zum Herunterladen und Ausführen: Sie starten den Server mit einer der oben genannten Optionen und verwenden LibreChat anschließend in Ihrem Browser.

Unter Windows ist [Docker Desktop](/docs/local/docker) der einfachste Weg.

</Callout>
