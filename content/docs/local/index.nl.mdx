<Callout type="info" title="Is er een Windows- of macOS-app?">

Nee. LibreChat is een zelf-gehoste webapplicatie, dus er is geen `.exe`, `.dmg` of AppImage om te downloaden: je installeert het zelf via een van de onderstaande methoden en gebruikt het vervolgens in je browser. Docker en npm draaien het op je eigen machine op Windows, macOS of Linux en serveren het op [http://localhost:3080](http://localhost:3080); op Windows is [Docker Desktop](/docs/local/docker) het eenvoudigste startpunt. De Helm chart implementeert het in plaats daarvan op een Kubernetes-cluster en is bereikbaar via het netwerk van je cluster.

</Callout>

<Callout type="info" title="Op zoek naar een desktop-installer?">

LibreChat is een self-hosted webapplicatie, geen native Windows-app of Linux AppImage. Er is geen installatieprogramma om te downloaden en uit te voeren: je start de server met een van de bovenstaande opties en gebruikt vervolgens LibreChat in je browser.

Op Windows is [Docker Desktop](/docs/local/docker) de eenvoudigste route.

</Callout>
