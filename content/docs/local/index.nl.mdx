<Callout type="info" title="Op zoek naar een desktop-installer?">

LibreChat is een self-hosted webapplicatie, geen native Windows-app of Linux AppImage. Er is geen installatieprogramma om te downloaden en uit te voeren: je start de server met een van de bovenstaande opties en gebruikt vervolgens LibreChat in je browser.

Op Windows is [Docker Desktop](/docs/local/docker) de eenvoudigste route.

</Callout>
