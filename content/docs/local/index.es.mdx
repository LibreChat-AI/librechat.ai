<Callout type="info" title="¿Existe una aplicación para Windows o macOS?">

No. LibreChat es una aplicación web autohospedada, por lo que no hay ningún `.exe`, `.dmg` o AppImage para descargar: usted mismo la instala utilizando uno de los métodos a continuación y luego la utiliza en su navegador. Docker y npm la ejecutan en su propia máquina en Windows, macOS o Linux y la sirven en [http://localhost:3080](http://localhost:3080); en Windows, [Docker Desktop](/docs/local/docker) es el punto de partida más sencillo. El Helm chart se despliega en un clúster de Kubernetes en su lugar, y se accede a él a través de la red de su clúster.

</Callout>

<Callout type="info" title="¿Buscas un instalador de escritorio?">

LibreChat es una aplicación web autohospedada, no una aplicación nativa de Windows o un AppImage de Linux. No hay ningún instalador para descargar y ejecutar: inicias el servidor usando una de las opciones anteriores y luego usas LibreChat en tu navegador.

En Windows, [Docker Desktop](/docs/local/docker) es la ruta más sencilla.

</Callout>
