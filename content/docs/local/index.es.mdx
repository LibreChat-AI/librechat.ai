<Callout type="info" title="¿Buscas un instalador de escritorio?">

LibreChat es una aplicación web autohospedada, no una aplicación nativa de Windows o un AppImage de Linux. No hay ningún instalador para descargar y ejecutar: inicias el servidor usando una de las opciones anteriores y luego usas LibreChat en tu navegador.

En Windows, [Docker Desktop](/docs/local/docker) es la ruta más sencilla.

</Callout>
