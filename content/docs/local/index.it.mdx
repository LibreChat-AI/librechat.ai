<Callout type="info" title="Cerchi un programma di installazione desktop?">

LibreChat è un'applicazione web self-hosted, non un'app nativa Windows o un AppImage Linux. Non c'è alcun programma di installazione da scaricare ed eseguire: si avvia il server utilizzando una delle opzioni sopra indicate, quindi si utilizza LibreChat nel proprio browser.

Su Windows, [Docker Desktop](/docs/local/docker) è la strada più semplice.

</Callout>
