<Callout type="info" title="Vous cherchez un installateur pour ordinateur ?">

LibreChat est une application web auto-hébergée, et non une application Windows native ou une AppImage Linux. Il n'y a pas d'installateur à télécharger et à exécuter : vous démarrez le serveur en utilisant l'une des options ci-dessus, puis vous utilisez LibreChat dans votre navigateur.

Sur Windows, [Docker Desktop](/docs/local/docker) est la méthode la plus simple.

</Callout>
