<Callout type="info" title="Existe-t-il une application Windows ou macOS ?">

Non. LibreChat est une application web auto-hébergée, il n'y a donc aucun fichier `.exe`, `.dmg` ou AppImage à télécharger : vous l'installez vous-même en utilisant l'une des méthodes ci-dessous, puis vous l'utilisez dans votre navigateur. Docker et npm l'exécutent sur votre propre machine sous Windows, macOS ou Linux et le servent à l'adresse [http://localhost:3080](http://localhost:3080) ; sous Windows, [Docker Desktop](/docs/local/docker) est le point de départ le plus simple. Le chart Helm le déploie plutôt sur un cluster Kubernetes, et il est accessible via le réseau de votre cluster.

</Callout>

<Callout type="info" title="Vous cherchez un installateur pour ordinateur ?">

LibreChat est une application web auto-hébergée, et non une application Windows native ou une AppImage Linux. Il n'y a pas d'installateur à télécharger et à exécuter : vous démarrez le serveur en utilisant l'une des options ci-dessus, puis vous utilisez LibreChat dans votre navigateur.

Sur Windows, [Docker Desktop](/docs/local/docker) est la méthode la plus simple.

</Callout>
