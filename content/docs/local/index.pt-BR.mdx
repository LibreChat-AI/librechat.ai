<Callout type="info" title="Existe um aplicativo para Windows ou macOS?">

Não. O LibreChat é uma aplicação web auto-hospedada, portanto não há nenhum `.exe`, `.dmg` ou AppImage para baixar: você mesmo o instala usando um dos métodos abaixo e, em seguida, utiliza-o em seu navegador. Docker e npm executam-no em sua própria máquina no Windows, macOS ou Linux e disponibilizam-no em [http://localhost:3080](http://localhost:3080); no Windows, o [Docker Desktop](/docs/local/docker) é o ponto de partida mais simples. O Helm chart, por outro lado, realiza o deploy em um cluster Kubernetes e é acessado através da rede do seu cluster.

</Callout>

<Callout type="info" title="Procurando por um instalador para desktop?">

LibreChat é uma aplicação web auto-hospedada, não um aplicativo nativo do Windows ou AppImage do Linux. Não há um instalador para baixar e executar: você inicia o servidor usando uma das opções acima e, em seguida, usa o LibreChat no seu navegador.

No Windows, o [Docker Desktop](/docs/local/docker) é o caminho mais simples.

</Callout>
