<Callout type="info" title="是否有 Windows 或 macOS 应用程序？">

不是。LibreChat 是一个自托管的 Web 应用程序，因此没有可供下载的 `.exe`、`.dmg` 或 AppImage 文件：你需要使用下述方法之一自行安装，然后在浏览器中使用它。Docker 和 npm 会在你的 Windows、macOS 或 Linux 机器上运行它，并通过 [http://localhost:3080](http://localhost:3080) 提供服务；在 Windows 上，[Docker Desktop](/docs/local/docker) 是最简单的入门方式。Helm chart 则部署到 Kubernetes 集群中，并通过你的集群网络进行访问。

</Callout>

<Callout type="info" title="正在寻找桌面安装程序？">

LibreChat 是一个自托管的 Web 应用程序，而不是原生的 Windows 应用程序或 Linux AppImage。没有可供下载和运行的安装程序：您需要使用上述选项之一启动服务器，然后在浏览器中使用 LibreChat。

在 Windows 上，[Docker Desktop](/docs/local/docker) 是最简单的途径。

</Callout>
