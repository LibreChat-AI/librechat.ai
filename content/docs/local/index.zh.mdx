<Callout type="info" title="正在寻找桌面安装程序？">

LibreChat 是一个自托管的 Web 应用程序，而不是原生的 Windows 应用程序或 Linux AppImage。没有可供下载和运行的安装程序：您需要使用上述选项之一启动服务器，然后在浏览器中使用 LibreChat。

在 Windows 上，[Docker Desktop](/docs/local/docker) 是最简单的途径。

</Callout>
