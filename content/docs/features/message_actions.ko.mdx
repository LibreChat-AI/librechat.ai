# 메시지 작업 [#message-actions]

메시지 작업은 사용 가능한 경우 대화 턴 아래에 나타납니다. 사용자 턴은 오른쪽 정렬된 말풍선을 사용하며, 어시스턴트 턴은 전체 너비 응답 레이아웃을 유지합니다. 응답이 스트리밍되는 동안 적용할 수 없는 작업은 응답이 완료될 때까지 숨겨집니다.

## 편집 및 재실행 [#edit-and-rerun]

**편집**을 선택하여 사용자 메시지나 편집 가능한 어시스턴트 응답을 변경하세요. 편집기에서는 변경 사항을 적용하는 두 가지 방법을 제공합니다:

- **Save**는 다른 응답을 생성하지 않고 기존 메시지를 업데이트합니다.
- **Update & rerun**은 편집된 메시지로부터 새로운 형제 응답을 생성합니다.

구조화된 어시스턴트 응답은 모든 편집 가능한 텍스트 및 추론 부분에 대해 하나의 편집기를 사용합니다. 도구 호출, 오류, 아티팩트 및 도구 호출에 첨부된 텍스트는 계속 표시되지만 읽기 전용으로 유지됩니다. 비어 있는 편집 부분은 저장할 수 없습니다.

둘 이상의 어시스턴트 파트가 변경된 경우, 다시 실행하지 않고 편집 내용을 저장하세요. 한 번의 다시 실행으로 하나의 편집된 어시스턴트 파트만 반영할 수 있습니다. 다중 파트 저장은 순서대로 적용되며, 오류 발생 전에 저장된 파트는 대화에 그대로 반영됩니다.

편집된 사용자 메시지를 다시 실행하면 해당 메시지의 파일, 선택된 수동 Skills, 인용된 컨텍스트가 유지됩니다. 편집된 어시스턴트 응답을 다시 실행하면 선택된 수동 Skills 및 인용문과 함께 상위 사용자 턴이 다시 재생됩니다.

편집하는 동안 `Ctrl`/`Cmd` + `S`를 눌러 저장하거나, `Ctrl`/`Cmd` + `Enter`를 눌러 업데이트 및 재실행하거나, `Escape`를 눌러 취소할 수 있습니다.

## 복사 및 포크 (Copy and Fork) [#copy-and-fork]

**Copy**는 구조화된 콘텐츠 부분과 처리된 인용을 포함한 전체 메시지를 클립보드 텍스트로 직렬화합니다. 스트리밍 중인 응답에 대해서는 클립보드에 불완전한 답변이 복사되지 않도록 **Copy** 기능이 제한됩니다.

**Fork**을 사용하여 선택한 메시지에서 대화를 분기할 수 있습니다. 자세한 내용은 [Forking Conversations](/docs/features/fork)를 참조하세요. 편집, 재실행, 이어가기, 피드백, 읽어주기 및 포크(fork) 작업의 사용 가능 여부는 endpoint와 메시지 상태에 따라 결정됩니다.
