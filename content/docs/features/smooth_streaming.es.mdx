---
title: Streaming fluido
icon: Waves
description: >-
  Difuminar el texto del asistente recién transmitido en la conversación a
  medida que llega.
---

Smooth Streaming facilita el seguimiento de las respuestas en vivo al desvanecer la aparición de las nuevas palabras transmitidas. Se aplica al mensaje más reciente del asistente mientras se genera una respuesta, incluyendo el texto de razonamiento expandido.

La configuración está habilitada de forma predeterminada. Para cambiarla, abre **Settings → Chat → Messages** y activa o desactiva **Smooth streaming text (fade in new words)**.

Smooth Streaming es solo visual. No retrasa la entrega de tokens, no cambia el contenido de la respuesta ni altera los mensajes guardados. El texto cargado previamente se trata como contenido existente cuando una transmisión se reconecta o una conversación cambia, por lo que no se vuelve a reproducir la animación. Las regiones estructuradas como código, matemáticas, artefactos, citas y el contenido de la interfaz de usuario de MCP no se animan.

LibreChat deshabilita automáticamente la animación cuando el dispositivo informa la preferencia de accesibilidad `prefers-reduced-motion`, independientemente del interruptor guardado.
