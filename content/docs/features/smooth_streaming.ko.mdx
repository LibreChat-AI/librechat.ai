Smooth Streaming은 새로 스트리밍되는 단어를 서서히 나타나게 함으로써 실시간 응답을 더 쉽게 따라갈 수 있도록 합니다. 이는 응답이 생성되는 동안 최신 어시스턴트 메시지에 적용되며, 확장된 추론 텍스트도 포함됩니다. [parent activity phases](/docs/features/agents#activity-groups)를 사용하는 에이전트의 경우, 새로 생성된 단계 요약이 표시된 활동을 접힌 그룹으로 통합할 수 있게 해줍니다.

이 설정은 기본적으로 활성화되어 있습니다. 변경하려면 **Settings → Chat → Messages**를 열고 **Smooth streaming text (fade in new words)**를 토글하세요.

Smooth Streaming은 시각적인 효과일 뿐입니다. 토큰 전달을 지연시키거나, 응답 내용을 변경하거나, 저장된 메시지를 수정하지 않습니다. 이전에 로드된 텍스트와 활동 단계는 스트림이 재연결되거나 대화가 변경될 때 기존 콘텐츠로 처리되므로, 해당 요소들의 등장 애니메이션이 다시 재생되지 않습니다. 페이드(fade) 효과는 코드, 수학, 아티팩트, 인용문, MCP UI 콘텐츠와 같은 구조화된 영역에는 적용되지 않으며, 상위 활동 단계는 자체적인 접기(fold) 전환을 사용합니다.

LibreChat은 기기가 `prefers-reduced-motion` 접근성 설정을 보고할 경우, 저장된 토글 상태와 관계없이 자동으로 애니메이션을 비활성화합니다.

## 경과 생성 시간 [#elapsed-generation-time]

최신 어시스턴트 응답이 스트리밍되는 동안, LibreChat은 응답 하단에 경과된 생성 시간을 초 또는 분 단위로 간략하게 표시합니다. 타이머는 메시지가 제출될 때 시작되며 동일 세션 내 탐색 중에도 해당 시작 시간을 유지합니다. 전체 새로고침 후 원래의 클라이언트 측 시작 시간 없이 라이브 스트림이 복구되는 경우, 응답이 다시 마운트될 때부터 시간이 측정됩니다.

타이머는 Smooth Streaming 설정과는 별개이며, 페이드 애니메이션이 비활성화된 경우에도 계속 사용할 수 있습니다. 타이머는 생성 작업이 활성화된 동안 최신 응답에만 나타나며 메시지 내용으로 저장되지 않습니다.
