---

Smooth Streaming은 새로 스트리밍되는 단어를 서서히 나타나게 하여 실시간 응답을 더 쉽게 따라갈 수 있도록 합니다. 이 기능은 확장된 추론 텍스트를 포함하여 응답이 생성되는 동안 최신 어시스턴트 메시지에 적용됩니다.

이 설정은 기본적으로 활성화되어 있습니다. 변경하려면 **Settings → Chat → Messages**를 열고 **Smooth streaming text (fade in new words)**를 토글하세요.

Smooth Streaming은 시각적인 효과일 뿐입니다. 토큰 전달을 지연시키거나, 응답 내용을 변경하거나, 저장된 메시지를 수정하지 않습니다. 이전에 로드된 텍스트는 스트림이 재연결되거나 대화가 변경될 때 기존 콘텐츠로 처리되므로 애니메이션이 다시 재생되지 않습니다. 코드, 수학, 아티팩트, 인용문, MCP UI 콘텐츠와 같은 구조화된 영역은 애니메이션 처리되지 않습니다.

LibreChat은 기기가 `prefers-reduced-motion` 접근성 설정을 보고할 경우, 저장된 토글 상태와 관계없이 자동으로 애니메이션을 비활성화합니다.
