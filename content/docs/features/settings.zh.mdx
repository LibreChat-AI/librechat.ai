打开您的账户菜单并选择 **Settings**，以管理 LibreChat 的个人偏好设置和数据控制。使用 **Search settings** 可以通过标签或相关关键词查找控制项；选择搜索结果将打开对应的选项卡和部分。设置布局可适配移动端屏幕，且不会隐藏选项卡导航。

## 常规 [#general]

**Display chat title in tab** 使用当前对话标题作为浏览器标签页标题。此功能默认开启，并存储在当前浏览器中。将其关闭可使每个标签页始终显示部署的应用标题。新对话在获得正式对话标题之前，将继续使用应用标题。

**时间格式**控制时间显示是采用系统惯例、12 小时制还是 24 小时制。**系统**选项会读取当前浏览器的区域设置，而非所选的 LibreChat 翻译语言。此选项适用于消息时间戳、定时聊天控件和摘要、密钥过期和余额充值日期、智能体和提示词版本日期、记忆以及项目聊天列表。

**Week Starts On** 控制日历风格的周几列表是遵循系统惯例、周日还是周一。系统惯例可能会解析为其他地区的起始日，例如周六。这会改变“定时聊天”（Scheduled Chats）中周几控件和摘要的顺序，但不会改变定时任务运行的具体日期。

两种区域设置偏好都存储在当前浏览器中，因此不同的设备可以遵循各自的区域设置或显式覆盖。

**在移动端侧边栏旁显示聊天**（位于**布局**下）默认处于关闭状态。启用后，移动端抽屉菜单将停在视口的 80% 处，并留出一部分当前对话可见。点击该区域即可关闭抽屉。此偏好设置存储在当前浏览器中；请参阅 [Mobile Drawer](/docs/features/navigation#mobile-drawer)。

**已归档聊天**会打开已归档对话管理器。新归档的聊天按归档时间排序；没有归档时间戳的旧记录则回退至其创建日期。归档或恢复聊天不会被计为新的对话活动。请参阅 [侧边栏与导航](/docs/features/navigation#archived-conversations)。

## 聊天 [#chat]

**聊天打开时自动滚动至最新消息**会将新打开的对话跳转至其最新渲染的消息。关闭此功能可在返回聊天时保留当前的滚动位置。LibreChat 会在跳转前等待目标对话行完成渲染，即使在导航和消息加载完成时间不一致的情况下也是如此。

**Resize images before upload** 允许用户在发送前在浏览器中缩小大型 JPEG、PNG 和 WebP 文件。此首选项默认为关闭，并存储在当前浏览器中。

管理员可以控制这是否仍然是一个个人选择。如果 [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) 被显式设置为 `true` 或 `false`，LibreChat 将强制执行该值并锁定用户开关。如果省略该字段，则应用用户的设置。

**Paste long text as a file** 默认处于启用状态，并存储在当前浏览器中。当“Upload as Text”上下文上传功能可用时，在普通消息编辑器中粘贴超过 2,500 个字符的内容会将其作为 `pasted-text.txt` 附加，而不是直接填入输入框。较短的粘贴内容以及在没有 `context` 功能的情况下进行的粘贴将保持内联。请参阅 [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file)。

**Collapse long user messages** 默认处于关闭状态。启用后，高度超过 256 像素的用户消息将以紧凑预览形式显示，并带有 **Show more**（显示更多）和 **Show less**（收起）控件。此折叠仅为视觉效果：完整消息仍可用于复制、浏览器搜索和辅助技术。

**解析消息中的 LaTeX** 默认处于启用状态。该开关用于控制歧义的单美元符号 `$...$` 行内数学公式形式，它遵循边界规则，以确保像 `$50` 这样类似货币的文本保持原样。当该开关关闭时，无歧义的 `$$...$$`、`\(...\)` 和 `\[...\]` 数学公式仍受支持。行内代码、代码块和自动链接不会被解析为单美元符号数学公式。

## 键盘快捷键 [#keyboard-shortcuts]

从账户菜单中打开 **Keyboard Shortcuts** 以查看或自定义快捷键绑定。**Keyboard Shortcuts** 开关默认处于开启状态。将其关闭将禁用所有快捷键并从界面中移除快捷键提示，同时保留自定义绑定。再次从账户菜单中打开同一对话框即可重新开启快捷键。

快捷键启用状态和自定义绑定存储在当前浏览器中。即使关闭快捷键，绑定行仍保持可见，但在重新启用快捷键之前，编辑和重置控件将保持禁用状态。

## 数据控制 [#data-controls]

**数据控制**选项卡将个人数据管理操作集中在一处：

- **Manage files** 会打开已上传文件的管理器。
- **导入对话**功能用于导入受支持的对话导出文件。
- **共享聊天**用于列出和管理已发布的对话链接。
- **Provider API keys** 管理为已配置的提供商所提供的密钥。
- **撤销所有提供商 API 密钥**将移除所有用户提供的提供商密钥。
- **Default stateful workspace**（默认有状态工作区），位于 **Code execution**（代码执行）下，用于选择为新创建的 Agent 建议的工作区范围。它仅在 Stateful Code Sessions（有状态代码会话）可用时才会显示；更改此设置不会启用有状态会话，也不会更改现有的 Agent。
- **Delete TTS cache storage** 会删除浏览器中缓存的文本转语音音频；如果缓存为空，此选项将不可用。
- **归档所有聊天**会在确认后将活跃对话移至**已归档聊天**，而不会将其删除。
- **删除所有聊天**会在确认后永久移除用户的对话。

数据删除和密钥撤销操作由服务器支持，且可能是不可逆的。仅限浏览器的偏好设置和缓存仅适用于当前浏览器配置文件，而非所有设备。
