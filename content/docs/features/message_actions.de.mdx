# Nachrichtenaktionen [#message-actions]

Nachrichtenaktionen erscheinen unter einem Konversationsschritt, sobald sie verfügbar sind. Benutzereingaben verwenden rechtsbündige Sprechblasen, während Assistentenantworten ein Layout über die volle Breite beibehalten. Aktionen, die nicht auf eine Antwort angewendet werden können, solange diese noch gestreamt wird, bleiben ausgeblendet, bis die Antwort vollständig abgeschlossen ist.

## Bearbeiten und erneut ausführen [#edit-and-rerun]

Wählen Sie **Edit**, um eine Benutzernachricht oder eine bearbeitbare Antwort des Assistenten zu ändern. Der Editor bietet zwei Möglichkeiten, die Änderung anzuwenden:

- **Speichern** aktualisiert die bestehende Nachricht, ohne eine weitere Antwort zu generieren.
- **Update & rerun** erstellt eine neue gleichrangige Antwort aus der bearbeiteten Nachricht.

Strukturierte Assistentenantworten verwenden einen Editor für alle bearbeitbaren Text- und Reasoning-Teile. Tool-Aufrufe, Fehler, Artefakte und an Tool-Aufrufe angehängter Text bleiben sichtbar, sind jedoch schreibgeschützt. Leere bearbeitete Teile können nicht gespeichert werden.

Wenn mehr als ein Assistant-Teil geändert wird, speichern Sie die Bearbeitungen, ohne sie erneut auszuführen; ein erneuter Durchlauf kann jeweils nur einen bearbeiteten Assistant-Teil übernehmen. Mehrteilige Speicherungen werden in der entsprechenden Reihenfolge angewendet, und alle Teile, die vor einem Fehler gespeichert wurden, bleiben in der Konversation erhalten.

Das erneute Ausführen einer bearbeiteten Benutzernachricht behält deren Dateien, ausgewählte manuelle Skills und zitierten Kontext bei. Das erneute Ausführen einer bearbeiteten Antwort des Assistenten wiederholt den übergeordneten Benutzer-Turn mit den dazugehörigen ausgewählten manuellen Skills und Zitaten.

Verwenden Sie während der Bearbeitung `Ctrl`/`Cmd` + `S` zum Speichern, `Ctrl`/`Cmd` + `Enter` zum Aktualisieren und erneuten Ausführen oder `Escape` zum Abbrechen.

## Kopieren und Forken [#copy-and-fork]

**Kopieren** serialisiert die vollständige Nachricht, einschließlich strukturierter Inhaltsbestandteile und verarbeiteter Zitate, in den Zwischenablagetext. Das Kopieren ist für Antworten, die noch gestreamt werden, deaktiviert, damit die Zwischenablage keine unvollständige Antwort erhält.

Verwenden Sie **Fork**, um eine Konversation von einer ausgewählten Nachricht aus zu verzweigen. Weitere Informationen finden Sie unter [Forking Conversations](/docs/features/fork). Der endpoint und der Nachrichtenstatus bestimmen, ob die Aktionen Bearbeiten, Erneut ausführen, Fortsetzen, Feedback, Vorlesen und Fork verfügbar sind.
