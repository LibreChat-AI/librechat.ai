Smooth Streaming macht Live-Antworten leichter lesbar, indem neu gestreamte Wörter sanft eingeblendet werden. Dies gilt für die neueste Assistenten-Nachricht, während eine Antwort generiert wird, einschließlich des erweiterten Reasoning-Textes.

Die Einstellung ist standardmäßig aktiviert. Um sie zu ändern, öffnen Sie **Settings → Chat → Messages** und schalten Sie **Smooth streaming text (fade in new words)** um.

Smooth Streaming ist rein visueller Natur. Es verzögert nicht die Token-Übermittlung, ändert nicht den Antwortinhalt und verändert keine gespeicherten Nachrichten. Zuvor geladener Text wird als bereits vorhandener Inhalt behandelt, wenn ein Stream die Verbindung wiederherstellt oder eine Konversation gewechselt wird, sodass die Animation nicht erneut abgespielt wird. Strukturierte Bereiche wie Code, mathematische Formeln, Artefakte, Zitate und MCP UI-Inhalte werden nicht animiert.

LibreChat deaktiviert die Animation automatisch, wenn das Gerät die Barrierefreiheitseinstellung `prefers-reduced-motion` meldet, unabhängig von der gespeicherten Einstellung.
