---
title: 平滑流式传输
icon: Waves
description: 淡化新流式传输的文本，并平滑地折叠已生成的 Agent 阶段。
---

平滑流式传输（Smooth Streaming）通过淡入新流式传输的文字，使实时响应更易于阅读。它适用于生成响应时的最新助手消息，包括展开的推理文本。对于具有 [parent activity phases](/docs/features/agents#activity-groups) 的 Agent，它还允许新生成的阶段摘要将可见活动折叠到其收起的组中。

该设置默认处于启用状态。若要更改此设置，请打开 **Settings → Chat → Messages** 并切换 **Smooth streaming text (fade in new words)**。

平滑流式传输（Smooth Streaming）仅限于视觉效果。它不会延迟 Token 的交付、更改响应内容或修改已保存的消息。当流重新连接或对话发生更改时，先前加载的文本和活动阶段会被视为现有内容，因此它们不会重新播放进入动画。淡入效果不适用于代码、数学公式、工件（Artifacts）、引用和 MCP UI 内容等结构化区域；父级活动阶段使用其自身的折叠过渡效果。

当设备报告 `prefers-reduced-motion` 辅助功能偏好时，LibreChat 会自动禁用动画，无论保存的开关状态如何。

## 经过的生成时间 [#elapsed-generation-time]

当最新的助手响应正在流式传输时，LibreChat 会在响应下方以紧凑的秒或分钟格式显示其已耗用的生成时间。计时器从消息提交时开始，并在同一会话导航期间保持该开始时间。如果实时流在完全重新加载后恢复且没有原始的客户端开始时间，则计时从响应重新挂载时开始。

计时器与 Smooth Streaming 设置是分开的，即使在禁用淡入动画时也依然可用。它仅在生成处于活动状态时出现在最新回复上，且不会作为消息内容保存。
