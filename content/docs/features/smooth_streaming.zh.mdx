---
title: 平滑流式传输
icon: Waves
description: 将新流式传输的助手文本在到达时淡入对话中。
---

平滑流式传输（Smooth Streaming）通过淡入新流式传输的文字，使实时响应更易于阅读。它适用于生成响应时的最新助手消息，包括展开的推理文本。

该设置默认处于启用状态。若要更改此设置，请打开 **Settings → Chat → Messages** 并切换 **Smooth streaming text (fade in new words)**。

平滑流式传输（Smooth Streaming）仅限于视觉效果。它不会延迟 Token 的交付、更改响应内容或修改已保存的消息。当流重新连接或对话发生更改时，先前加载的文本会被视为现有内容，因此不会重新播放动画。代码、数学公式、Artifacts、引用和 MCP UI 内容等结构化区域不会进行动画处理。

当设备报告 `prefers-reduced-motion` 辅助功能偏好时，LibreChat 会自动禁用动画，无论保存的开关状态如何。
