# Actions sur les messages [#message-actions]

Les actions de message apparaissent sous un tour de conversation lorsqu'elles sont disponibles. Les tours de l'utilisateur utilisent des bulles alignées à droite, tandis que les tours de l'assistant conservent une mise en page de réponse sur toute la largeur. Les actions qui ne peuvent pas s'appliquer à une réponse pendant qu'elle est en cours de diffusion sont masquées jusqu'à ce que la réponse soit terminée.

## Modifier et relancer [#edit-and-rerun]

Choisissez **Edit** pour modifier un message utilisateur ou une réponse modifiable de l'assistant. L'éditeur propose deux manières d'appliquer la modification :

- **Save** met à jour le message existant sans générer une autre réponse.
- **Mettre à jour et relancer** crée une nouvelle réponse sœur à partir du message modifié.

Les réponses structurées de l'assistant utilisent un seul éditeur pour tout le texte modifiable et les parties de raisonnement. Les appels d'outils, les erreurs, les artefacts et le texte associé aux appels d'outils restent visibles mais en lecture seule. Les parties modifiées vides ne peuvent pas être enregistrées.

Si plus d'une partie de l'assistant est modifiée, enregistrez les modifications sans relancer ; une seule réexécution peut prendre en charge une partie d'assistant modifiée. Les enregistrements en plusieurs parties sont appliqués dans l'ordre, et toutes les parties enregistrées avant une erreur restent reflétées dans la conversation.

Relancer un message utilisateur modifié préserve ses fichiers, les Skills manuels sélectionnés et le contexte cité. Relancer une réponse de l'assistant modifiée rejoue le tour utilisateur parent avec ses Skills manuels sélectionnés et ses citations.

Pendant la modification, utilisez `Ctrl`/`Cmd` + `S` pour enregistrer, `Ctrl`/`Cmd` + `Enter` pour mettre à jour et relancer, ou `Escape` pour annuler.

## Copier et forker [#copy-and-fork]

**Copier** sérialise le message complet, y compris les parties de contenu structuré et les citations traitées, dans le texte du presse-papiers. La fonction Copier est désactivée pour la réponse en cours de streaming afin que le presse-papiers ne reçoive pas une réponse partielle.

Utilisez **Fork** pour créer une branche de conversation à partir d'un message sélectionné. Voir [Forking Conversations](/docs/features/fork) pour plus de détails. L'endpoint et l'état du message déterminent si les actions modifier, relancer, continuer, feedback, lecture à voix haute et fork sont disponibles.
