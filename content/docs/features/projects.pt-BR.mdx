Projetos permitem que cada usuário organize conversas relacionadas em espaços de trabalho nomeados. Eles são úteis para fluxos de trabalho de longa duração, equipes, clientes, aulas ou qualquer tópico onde você deseje um conjunto focado de chats sem depender apenas da pesquisa.

<Callout type="info" title="Disponibilidade">
  Projetos foram adicionados ao LibreChat na **v0.8.7**. Não existe nenhuma configuração no `librechat.yaml`, variável de ambiente ou permissão de função que os habilite ou oculte, portanto, todo usuário conectado em uma versão compatível possui o recurso. Se você não conseguir encontrar Projetos em lugar nenhum na interface, a instância está executando uma versão mais antiga e precisa ser atualizada.
</Callout>

## O que os Projects fazem [#what-projects-do]

- Agrupe conversas em um workspace nomeado com uma descrição opcional
- Inicie um novo chat já vinculado a um projeto
- Mover uma conversa existente entre projetos ou remover sua atribuição de projeto
- Navegue, ordene, mova, remova ou exclua chats do espaço de trabalho do projeto
- Pesquise projetos por nome ou descrição e ordene por atividade mais recente, data de criação ou nome
- Edite ou exclua projetos a partir do painel, da área de trabalho ou da barra lateral

Os Projects são pessoais para o usuário que os cria. Outros usuários não veem sua lista de projetos, e um projeto não pode ser compartilhado ou transferido.

Um projeto é apenas um agrupamento. Ele possui um nome e uma descrição opcional, e não adiciona instruções, arquivos ou configurações de modelo em nível de projeto aos chats contidos nele.

## Criar um Projeto [#create-a-project]

<Steps>
<Step>

**Abra a página de projetos.** Na barra lateral, o cabeçalho da seção **Projects** possui um botão **All projects** que a abre.

</Step>
<Step>

**Escolha New project**, que está sempre disponível no cabeçalho da página de projetos.

</Step>
<Step>

**Dê um nome ao projeto.** Um nome é obrigatório e uma descrição é opcional. O LibreChat abrirá então o espaço de trabalho do projeto.

</Step>
</Steps>

A seção **Projects** na barra lateral também possui um botão **New project**, mas apenas enquanto você ainda não tiver projetos. Essa seção começa recolhida até que você a expanda ou crie seu primeiro projeto, portanto, a página de projetos é o ponto de entrada confiável.

Os nomes dos projetos são limitados a 100 caracteres e as descrições a 1000 caracteres. Nomes de projetos duplicados são permitidos.

O painel de Projects exibe cada projeto como um cartão de pasta com sua descrição e contagem de chats.

## Trabalhar em um Projeto [#work-in-a-project]

Abra um projeto para ver sua descrição e os chats atribuídos. A barra de ferramentas do workspace pode ordenar os chats por última atualização ou data de criação. Use **New chat in _project_** para abrir um compositor com escopo definido; o chip do projeto confirma que a nova conversa será atribuída a esse projeto. A barra lateral mostra a mesma ação em cada linha de projeto.

Cada chat de projeto possui um menu de opções com estas ações:

- **Change project** abre um seletor de projetos pesquisável
- **Remove from project** mantém a conversa, mas remove sua atribuição ao projeto
- **Delete** exclui a conversa após confirmação

## Mover Chats Existentes [#move-existing-chats]

Abra o menu de uma conversa e escolha **Change project**, então selecione o projeto ao qual deseja atribuí-la. Para remover um chat de um projeto, use **Remove from project**, que é exibido apenas para chats que já pertencem a um.

Um espaço de trabalho de projeto lista apenas os chats atribuídos a esse projeto. A lista de **Chats** na barra lateral não é filtrada e continua exibindo todas as conversas, incluindo aquelas atribuídas a projetos.

## Gerenciar Projetos [#manage-projects]

Cada projeto aparece na barra lateral. Use o menu do projeto para:

- Abra o workspace do projeto
- Edite o nome e a descrição do projeto
- Excluir o projeto

A página de projetos e o cabeçalho do workspace expõem as mesmas ações de editar e excluir.

Excluir um projeto remove a atribuição do projeto de seus chats. As conversas em si não são excluídas.

## Encontrar um Projeto [#find-a-project]

A página de projetos possui uma caixa de **Search projects** que corresponde aos nomes e descrições dos projetos, e um controle de ordenação que oferece **Latest activity**, **Created** e **Name**. Listas mais longas são paginadas com **Load more**.

## Notas [#notes]

- Novos chats iniciados a partir de um projeto mantêm essa atribuição quando a conversa é criada.
- As pesquisas de projeto não diferenciam maiúsculas de minúsculas e correspondem tanto a nomes quanto a descrições.
- Se um projeto for excluído enquanto você o estiver visualizando, o LibreChat o levará de volta à lista de projetos.
