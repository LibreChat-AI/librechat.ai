Projetos permitem que cada usuário organize conversas relacionadas em espaços de trabalho nomeados. Eles são úteis para fluxos de trabalho de longa duração, equipes, clientes, aulas ou qualquer tópico onde você deseje um conjunto focado de chats sem depender apenas da pesquisa.

## O que os Projects fazem [#what-projects-do]

- Agrupe conversas em um workspace nomeado com uma descrição opcional
- Inicie um novo chat já vinculado a um projeto
- Mover uma conversa existente entre projetos ou remover sua atribuição de projeto
- Navegue, ordene, mova, remova ou exclua chats do espaço de trabalho do projeto
- Pesquise projetos por nome ou descrição e ordene por atividade mais recente, data de criação ou nome
- Edite ou exclua projetos a partir do painel, da área de trabalho ou da barra lateral

Os Projects são pessoais para o usuário que os cria. Outros usuários não veem sua lista de projetos.

## Criar um Projeto [#create-a-project]

Abra **Projects** na barra lateral e escolha **New project**. Adicione um nome e, opcionalmente, uma descrição. Os nomes dos projetos podem conter até 100 caracteres e as descrições até 1.000 caracteres.

O painel de Projects exibe cada projeto como um cartão de pasta com sua descrição e contagem de chats. Use a barra de ferramentas do painel para pesquisar nomes e descrições ou classificar a lista pela atividade de chat mais recente, data de criação ou nome.

## Trabalhar em um Projeto [#work-in-a-project]

Abra um projeto para ver sua descrição e os chats atribuídos. A barra de ferramentas do workspace pode classificar os chats por última atualização ou data de criação. Use **New chat in project** para abrir um compositor com escopo definido; o chip do projeto confirma que a nova conversa será atribuída a esse projeto.

Cada chat de projeto possui um menu de opções com estas ações:

- **Change project** abre um seletor de projetos pesquisável
- **Remove from project** mantém a conversa, mas remove sua atribuição ao projeto
- **Delete** exclui a conversa após confirmação

## Mover Chats Existentes [#move-existing-chats]

Abra o menu de uma conversa e escolha **Change project**. Pesquise e selecione outro projeto para atribuir o chat. Escolha **Remove from project** quando a conversa deve permanecer no histórico sem um projeto.

A barra lateral inclui **All projects**, linhas de projeto e atalhos para iniciar um novo chat em um projeto. O histórico de conversas regular permanece disponível fora dos espaços de trabalho do projeto.

## Gerenciar Projetos [#manage-projects]

Use o menu de um projeto no painel, na área de trabalho ou na barra lateral para editar seu nome e descrição ou excluí-lo.

Excluir um projeto remove a atribuição do projeto de seus chats. As conversas em si não são excluídas.

## Notas [#notes]

- Novos chats iniciados a partir de um projeto mantêm essa atribuição quando a conversa é criada.
- As pesquisas de projeto não diferenciam maiúsculas de minúsculas e correspondem tanto a nomes quanto a descrições.
- Se um projeto for excluído enquanto você o estiver visualizando, o LibreChat o levará de volta à lista de projetos.
