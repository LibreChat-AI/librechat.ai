Projects를 사용하면 각 사용자가 관련 대화를 이름이 지정된 작업 공간으로 구성할 수 있습니다. 이는 장기적인 작업 흐름, 팀, 클라이언트, 수업 또는 검색에만 의존하지 않고 집중적인 대화 세트를 유지하려는 모든 주제에 유용합니다.

## 프로젝트의 역할 [#what-projects-do]

- 선택적 설명이 포함된 이름이 지정된 작업 공간(workspace)으로 대화 그룹화
- 특정 프로젝트로 범위가 지정된 새 채팅 시작하기
- 기존 대화를 프로젝트 간에 이동하거나 프로젝트 할당을 제거합니다.
- 프로젝트 작업 공간에서 채팅을 탐색, 정렬, 이동, 제거 또는 삭제하세요.
- 이름이나 설명으로 프로젝트를 검색하고 최근 활동, 생성 날짜 또는 이름순으로 정렬하세요.
- 대시보드, 작업 공간 또는 사이드바에서 프로젝트를 수정하거나 삭제하세요.

프로젝트는 이를 생성한 사용자 개인에게 귀속됩니다. 다른 사용자는 귀하의 프로젝트 목록을 볼 수 없습니다.

## 프로젝트 생성 [#create-a-project]

사이드바에서 **Projects**를 열고 **New project**를 선택하세요. 이름을 추가하고, 선택 사항으로 설명을 추가할 수 있습니다. 프로젝트 이름은 최대 100자, 설명은 최대 1,000자까지 입력할 수 있습니다.

Projects 대시보드는 각 프로젝트를 설명과 채팅 수가 포함된 폴더 카드로 표시합니다. 대시보드 툴바를 사용하여 이름과 설명을 검색하거나, 최근 채팅 활동, 생성 날짜 또는 이름순으로 목록을 정렬할 수 있습니다.

## 프로젝트에서 작업하기 [#work-in-a-project]

프로젝트를 열어 설명과 할당된 채팅을 확인하세요. 작업 공간 툴바를 사용하여 채팅을 마지막 업데이트 날짜 또는 생성 날짜순으로 정렬할 수 있습니다. **New chat in project**를 사용하여 범위가 지정된 컴포저를 여세요. 프로젝트 칩을 통해 새 대화가 해당 프로젝트에 할당될 것임을 확인할 수 있습니다.

각 프로젝트 채팅에는 다음과 같은 작업을 수행할 수 있는 오버플로우 메뉴가 있습니다:

- **Change project**는 검색 가능한 프로젝트 선택기를 엽니다.
- **Remove from project**는 대화 내용은 유지하되 프로젝트 할당을 해제합니다.
- **Delete**는 확인 후 대화를 삭제합니다.

## 기존 채팅 이동하기 [#move-existing-chats]

대화 메뉴를 열고 **Change project**를 선택하세요. 대화를 할당할 다른 프로젝트를 검색하여 선택하세요. 대화를 프로젝트 없이 기록에 남겨두려면 **Remove from project**를 선택하세요.

사이드바에는 **All projects**, 프로젝트 행, 그리고 프로젝트 내에서 새 채팅을 시작하기 위한 바로가기가 포함되어 있습니다. 일반 대화 기록은 프로젝트 작업 공간 외부에서 계속 사용할 수 있습니다.

## 프로젝트 관리 [#manage-projects]

대시보드, 작업 공간 또는 사이드바에서 프로젝트 메뉴를 사용하여 이름과 설명을 수정하거나 삭제할 수 있습니다.

프로젝트를 삭제하면 해당 채팅에서 프로젝트 할당이 제거됩니다. 대화 자체는 삭제되지 않습니다.

## 참고 사항 [#notes]

- 프로젝트에서 시작된 새 채팅은 대화가 생성될 때 해당 할당을 유지합니다.
- 프로젝트 검색은 대소문자를 구분하지 않으며 이름과 설명 모두와 일치합니다.
- 프로젝트를 보고 있는 도중에 해당 프로젝트가 삭제되면, LibreChat은 프로젝트 목록으로 돌아갑니다.
