Projects를 사용하면 각 사용자가 관련 대화를 이름이 지정된 작업 공간으로 구성할 수 있습니다. 이는 장기적인 작업 흐름, 팀, 클라이언트, 수업 또는 검색에만 의존하지 않고 집중적인 대화 세트를 유지하려는 모든 주제에 유용합니다.

<Callout type="info" title="가용성">
  Projects는 LibreChat **v0.8.7**에서 추가되었습니다. 이를 활성화하거나 숨길 수 있는 `librechat.yaml` 설정, 환경 변수 또는 역할 권한은 없으므로, 지원되는 버전을 사용하는 모든 로그인한 사용자는 이 기능을 사용할 수 있습니다. 인터페이스 어디에서도 Projects를 찾을 수 없다면, 해당 인스턴스가 이전 버전을 실행 중이므로 업데이트가 필요합니다.
</Callout>

## 프로젝트의 역할 [#what-projects-do]

- 선택적 설명이 포함된 이름이 지정된 작업 공간(workspace)으로 대화 그룹화
- 특정 프로젝트로 범위가 지정된 새 채팅 시작하기
- 기존 대화를 프로젝트 간에 이동하거나 프로젝트 할당을 제거합니다.
- 프로젝트 작업 공간에서 채팅을 탐색, 정렬, 이동, 제거 또는 삭제하세요.
- 이름이나 설명으로 프로젝트를 검색하고 최근 활동, 생성 날짜 또는 이름순으로 정렬하세요.
- 대시보드, 작업 공간 또는 사이드바에서 프로젝트를 수정하거나 삭제하세요.

프로젝트는 이를 생성한 사용자 개인에게 귀속됩니다. 다른 사용자는 귀하의 프로젝트 목록을 볼 수 없으며, 프로젝트를 공유하거나 이전할 수 없습니다.

프로젝트는 그룹화만을 위한 단위입니다. 프로젝트에는 이름과 선택적인 설명이 포함되지만, 그 안의 채팅에 프로젝트 수준의 지침, 파일 또는 모델 설정을 추가하지는 않습니다.

## 프로젝트 생성 [#create-a-project]

<Steps>
<Step>

**프로젝트 페이지를 엽니다.** 사이드바의 **Projects** 섹션 헤더에는 이를 여는 **All projects** 버튼이 있습니다.

</Step>
<Step>

**Choose New project**를 선택하세요. 이 옵션은 프로젝트 페이지 헤더에서 항상 사용할 수 있습니다.

</Step>
<Step>

**프로젝트 이름을 지정하세요.** 이름은 필수이며 설명은 선택 사항입니다. 이후 LibreChat이 프로젝트 작업 공간을 엽니다.

</Step>
</Steps>

사이드바의 **Projects** 섹션에도 **New project** 버튼이 있지만, 이는 아직 프로젝트가 하나도 없을 때만 나타납니다. 해당 섹션은 확장하거나 첫 번째 프로젝트를 생성하기 전까지는 접힌 상태로 시작되므로, 프로젝트 페이지가 가장 확실한 진입점입니다.

프로젝트 이름은 100자, 설명은 1000자까지로 제한됩니다. 프로젝트 이름은 중복될 수 있습니다.

Projects 대시보드는 각 프로젝트를 설명과 채팅 수가 포함된 폴더 카드로 표시합니다.

## 프로젝트에서 작업하기 [#work-in-a-project]

프로젝트를 열어 설명과 할당된 채팅을 확인하세요. 작업 공간 툴바를 사용하면 마지막 업데이트 날짜 또는 생성 날짜별로 채팅을 정렬할 수 있습니다. **New chat in _project_**를 사용하여 범위가 지정된 컴포저를 여세요. 프로젝트 칩을 통해 새 대화가 해당 프로젝트에 할당됨을 확인할 수 있습니다. 사이드바의 각 프로젝트 행에서도 동일한 작업을 수행할 수 있습니다.

각 프로젝트 채팅에는 다음과 같은 작업을 수행할 수 있는 오버플로우 메뉴가 있습니다:

- **Change project**는 검색 가능한 프로젝트 선택기를 엽니다.
- **Remove from project**는 대화 내용은 유지하되 프로젝트 할당을 해제합니다.
- **Delete**는 확인 후 대화를 삭제합니다.

## 기존 채팅 이동하기 [#move-existing-chats]

대화 메뉴를 열고 **Change project**를 선택한 다음, 할당할 프로젝트를 선택하세요. 채팅을 다시 꺼내려면 **Remove from project**를 사용하세요. 이 옵션은 이미 프로젝트에 속해 있는 채팅에만 표시됩니다.

프로젝트 작업 공간에는 해당 프로젝트에 할당된 채팅만 나열됩니다. 사이드바의 **Chats** 목록은 필터링되지 않으며 프로젝트에 할당된 대화를 포함한 모든 대화를 계속 표시합니다.

## 프로젝트 관리 [#manage-projects]

각 프로젝트는 사이드바에 나타납니다. 프로젝트 메뉴를 사용하여 다음을 수행할 수 있습니다:

- 프로젝트 작업 공간을 엽니다
- 프로젝트 이름과 설명을 수정하세요
- 프로젝트 삭제

프로젝트 페이지와 작업 공간 헤더는 동일한 편집 및 삭제 작업을 제공합니다.

프로젝트를 삭제하면 해당 채팅에서 프로젝트 할당이 제거됩니다. 대화 자체는 삭제되지 않습니다.

## 프로젝트 찾기 [#find-a-project]

프로젝트 페이지에는 프로젝트 이름과 설명을 검색할 수 있는 **Search projects** 상자가 있으며, **Latest activity**, **Created**, **Name**으로 정렬할 수 있는 정렬 컨트롤이 있습니다. 목록이 길어지면 **Load more**를 통해 페이지를 불러올 수 있습니다.

## 참고 사항 [#notes]

- 프로젝트에서 시작된 새 채팅은 대화가 생성될 때 해당 할당을 유지합니다.
- 프로젝트 검색은 대소문자를 구분하지 않으며 이름과 설명 모두와 일치합니다.
- 프로젝트를 보고 있는 도중에 해당 프로젝트가 삭제되면, LibreChat은 프로젝트 목록으로 돌아갑니다.
