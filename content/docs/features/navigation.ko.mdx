LibreChat의 사이드바는 대화 기록, 고정된 채팅, 프로젝트 및 배포 시 활성화된 추가 패널을 제공합니다. 사용 가능한 패널 목록에는 채팅, 북마크, 프롬프트, 메모리 및 Skills가 포함될 수 있습니다.

## 데스크톱 사이드바 [#desktop-sidebar]

사이드바 토글을 사용하여 탐색 창을 열거나 접을 수 있습니다. 탐색 레일에서 패널을 선택하거나, 설정된 경우 대화 검색을 사용하거나, **New chat**을 선택하여 대화를 시작하세요. 프로젝트는 고유한 사이드바 섹션과 프로젝트별 새 대화 바로가기를 가지고 있습니다. [Projects](/docs/features/projects)를 참조하세요.

고정된 대화는 별도의 페이지네이션 섹션을 가지며 일반 기록 목록과 독립적으로 로드됩니다. 대화를 고정하거나 고정 해제하면 해당 작업이 새로운 대화 활동으로 처리되지 않고 고정 상태만 변경됩니다.

## 모바일 서랍 [#mobile-drawer]

모바일 환경에서 사이드바는 기본적으로 전체 화면 서랍(drawer) 형태로 열립니다. 헤더에는 채팅에서 사용되는 것과 동일한 사이드바 토글, 현재 패널 이름, 레이블이 지정된 패널 전환기, 그리고 계정 제어 기능이 포함되어 있습니다. 대화 기록 패널이 활성화된 상태에서는 하단 바에 검색 기능이 나타나며, 엄지손가락으로 쉽게 누를 수 있는 **New chat** 작업 버튼 옆에 위치합니다.

브라우저 전용 **Settings > General > Layout > Show chat beside the sidebar on mobile** 설정은 기본적으로 꺼져 있습니다. 이 설정을 켜면 서랍(drawer)이 뷰포트의 80%로 제한되며, 현재 대화의 흐릿한 영역이 표시됩니다. 해당 영역을 탭하면 서랍이 닫히고 대화 화면으로 돌아갑니다.

터치 제스처를 사용하여 탐색할 수도 있습니다:

- 채팅 창을 오른쪽으로 스와이프하여 서랍(drawer)을 엽니다.
- 열려 있는 서랍 안에서 왼쪽으로 스와이프하여 닫으세요.

서랍(drawer)은 제스처를 따라 움직이며, 거리와 속도에 따라 열리거나 닫힌 상태로 고정됩니다. 기본 전체 너비 서랍의 경우, 버튼, 키보드, 대화 기반으로 닫으면 새로 로드된 콘텐츠를 이동시키지 않고 이미 배치된 채팅이 나타납니다. 채팅 스트립(chat strip)이 활성화되면 서랍과 표시된 대화가 함께 움직입니다. 모든 닫기 경로는 움직이는 표면이 다시 상호작용 가능해진 후 헤더 오프너나 채팅 창으로 포커스를 복원합니다. 수직 스크롤, 텍스트 필드, 텍스트 선택, 그리고 코드 블록과 같이 가로로 스크롤 가능한 콘텐츠는 자체 제어권을 유지합니다. 동작 줄이기(reduced-motion) 환경 설정이 적용되면 서랍 및 스트립 전환 효과가 제거됩니다.

## 보관된 대화 [#archived-conversations]

**설정 > 일반**에서 **보관된 채팅**을 열어 보관된 대화를 탐색하거나 복원하세요. 새로 보관된 채팅은 보관된 시간순으로 정렬됩니다. LibreChat이 해당 타임스탬프를 기록하기 전에 보관된 대화는 생성 날짜를 기준으로 정렬됩니다.

대화 내용을 삭제하지 않고 활성 대화 목록을 비우려면, **Settings > Data Controls > Your data** 아래에 있는 **Archive all chats**를 사용하고 해당 작업을 확인하세요.

대화 보관, 보관 해제, 고정 및 고정 해제 시 더 이상 대화의 채팅 활동 시간이 업데이트되지 않으므로, 기록 및 프로젝트 활동은 실제 대화 변경 사항을 기준으로 유지됩니다.
