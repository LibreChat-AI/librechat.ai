---
title: スムーズストリーミング
icon: Waves
description: 新しくストリーミングされたアシスタントのテキストが到着するたびに、会話にフェードインさせます。
---

Smooth Streamingは、新しくストリーミングされる単語をフェードインさせることで、ライブレスポンスを追いやすくします。これは、推論テキストの展開を含め、レスポンスの生成中における最新のアシスタントメッセージに適用されます。

この設定はデフォルトで有効になっています。変更するには、**Settings → Chat → Messages** を開き、**Smooth streaming text (fade in new words)** を切り替えてください。

Smooth Streamingは視覚的な演出のみです。トークンの配信を遅延させたり、レスポンスの内容を変更したり、保存されたメッセージを改変したりすることはありません。ストリームが再接続されたり会話が切り替わったりした際、以前に読み込まれたテキストは既存のコンテンツとして扱われるため、アニメーションが再再生されることはありません。コード、数式、アーティファクト、引用、MCP UIコンテンツなどの構造化された領域はアニメーション化されません。

LibreChatは、デバイスが `prefers-reduced-motion` アクセシビリティ設定を報告している場合、保存されたトグルの設定に関係なく、自動的にアニメーションを無効にします。
