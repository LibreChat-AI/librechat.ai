Smooth Streamingは、新しくストリーミングされた単語をフェードインさせることで、ライブレスポンスを追いやすくします。これは、推論テキストの展開を含め、レスポンスの生成中に最新のアシスタントメッセージに適用されます。[親アクティビティフェーズ](/docs/features/agents#activity-groups)を持つエージェントの場合、新しく生成されたフェーズの要約によって、表示されているアクティビティを折りたたまれたグループにまとめることも可能です。

この設定はデフォルトで有効になっています。変更するには、**Settings → Chat → Messages** を開き、**Smooth streaming text (fade in new words)** を切り替えてください。

Smooth Streamingは視覚的な演出のみを行う機能です。トークンの配信を遅延させたり、応答内容を変更したり、保存されたメッセージを改変したりすることはありません。ストリームが再接続されたり会話が切り替わったりした際、以前に読み込まれたテキストやアクティビティフェーズは既存のコンテンツとして扱われるため、それらの出現アニメーションが再再生されることはありません。フェード効果はコード、数式、アーティファクト、引用、MCP UIコンテンツなどの構造化された領域には適用されず、親となるアクティビティフェーズは独自の折りたたみ遷移を使用します。

LibreChatは、デバイスが `prefers-reduced-motion` アクセシビリティ設定を報告している場合、保存されたトグルの設定に関係なく、自動的にアニメーションを無効にします。

## 経過生成時間 [#elapsed-generation-time]

最新のアシスタントの応答がストリーミングされている間、LibreChatは応答の下に経過生成時間を秒または分単位でコンパクトに表示します。タイマーはメッセージが送信された時点で開始され、同じセッション内でのナビゲーション中もその開始時間を保持します。フルリロード後にクライアント側の元の開始時間なしでライブストリームが復元された場合、応答が再マウントされた時点で計測が開始されます。

タイマーは「Smooth Streaming」設定とは別個のものであり、フェードアニメーションが無効な場合でも利用可能です。タイマーは生成がアクティブな間の最新のレスポンスにのみ表示され、メッセージコンテンツとしては保存されません。
