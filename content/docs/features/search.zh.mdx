LibreChat 集成了 **Meilisearch**，通过提供一种快速高效的方式来搜索过往对话，从而提升了用户体验。Meilisearch 是一款功能强大的开源搜索引擎，以其速度快和易用性而闻名，这使其成为 LibreChat 这类需要快速访问海量数据的应用程序的绝佳选择。

![搜索关于香蕉的对话](https://github.com/danny-avila/LibreChat/assets/32828263/60ad41b0-1869-4ee9-848b-502b3a5557b5)


该集成允许用户：

- 从侧边栏搜索对话标题、标签以及已索引的消息内容
- 当对话的元数据或其消息之一匹配时，打开该对话
- 在对话历史记录中使用拼写容错功能，并获得快速的即时搜索结果
- 搜索消息和共享链接候选内容，页面大小超过 Meilisearch 旧版 20 条结果的请求默认值

LibreChat 在加载可见的对话页面之前，会合并 conversation-index 和 message-index 的匹配结果。搜索结果受限于 Meilisearch 配置的 `pagination.maxTotalHits`；LibreChat 查询使用的默认上限为 1,000 条命中记录。有关设置、同步和重新索引行为，请参阅 [Meilisearch Configuration Guide](/docs/configuration/meilisearch)。
