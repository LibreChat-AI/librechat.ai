Ouvrez votre menu de compte et choisissez **Settings** pour gérer les préférences personnelles et les contrôles de données de LibreChat. Utilisez **Search settings** pour trouver un contrôle par son étiquette ou des mots-clés associés ; la sélection d'un résultat ouvre l'onglet et la section correspondants. La disposition des paramètres s'adapte aux écrans mobiles sans masquer la navigation par onglets.

## Général [#general]

**Display chat title in tab** utilise le titre de la conversation actuelle comme titre de l'onglet du navigateur. Cette option est activée par défaut et stockée dans le navigateur actuel. Désactivez-la pour conserver le titre de l'application du déploiement dans chaque onglet. Les nouvelles conversations continuent d'utiliser le titre de l'application jusqu'à ce qu'elles reçoivent un titre de conversation réel.

**Format de l'horloge** contrôle si les heures utilisent la convention système, une horloge de 12 heures ou une horloge de 24 heures. **Système** lit les paramètres régionaux du navigateur actuel plutôt que la traduction LibreChat sélectionnée. Ce choix s'applique aux horodatages des messages, aux contrôles et résumés des discussions planifiées, aux dates d'expiration des clés et de recharge du solde, aux dates des versions d'Agents et de prompts, aux mémoires et aux listes de discussions de projets.

**Week Starts On** contrôle si les listes de jours de la semaine de type calendrier suivent la convention système, le dimanche ou le lundi. La convention système peut correspondre à un autre premier jour régional, comme le samedi. Cela modifie l'ordre des contrôles et des résumés des jours de la semaine pour les Chats planifiés sans changer les jours où un planning s'exécute.

Les deux préférences régionales sont stockées dans le navigateur actuel, de sorte que différents appareils peuvent suivre leur propre locale ou une substitution explicite.

**Show chat beside the sidebar on mobile**, sous **Layout**, est désactivé par défaut. Lorsqu'il est activé, le tiroir mobile s'arrête à 80 % de la fenêtre d'affichage et laisse une bande de la conversation actuelle visible. Appuyer sur cette bande ferme le tiroir. La préférence est stockée dans le navigateur actuel ; voir [Mobile Drawer](/docs/features/navigation#mobile-drawer).

**Archived chats** ouvre le gestionnaire de conversations archivées. Les chats nouvellement archivés sont triés par heure d'archivage ; les anciens enregistrements sans horodatage d'archivage sont classés par date de création. L'archivage ou la restauration d'un chat ne compte pas comme une nouvelle activité de conversation. Voir [Sidebar and Navigation](/docs/features/navigation#archived-conversations).

## Chat [#chat]

**Auto-Scroll to latest message on chat open** déplace une conversation nouvellement ouverte vers son message le plus récent. Désactivez cette option pour conserver la position de défilement actuelle lors du retour à une discussion. LibreChat attend que les lignes de la conversation cible soient rendues avant d'atterrir, y compris lorsque la navigation et le chargement des messages se terminent à des moments différents.

**Redimensionner les images avant le téléchargement** permet à un utilisateur de réduire la taille de fichiers JPEG, PNG et WebP volumineux dans le navigateur avant de les envoyer. Cette préférence est désactivée par défaut et est enregistrée dans le navigateur actuel.

Les administrateurs contrôlent si cela reste un choix personnel. Si [`fileConfig.clientImageResize.enabled`](/docs/configuration/librechat_yaml/object_structure/config#clientimageresize) est explicitement défini sur `true` ou `false`, LibreChat applique cette valeur et verrouille le bouton de bascule de l'utilisateur. Si le champ est omis, le paramètre de l'utilisateur s'applique.

**Coller un long texte sous forme de fichier** est activé par défaut et stocké dans le navigateur actuel. Lorsque les téléchargements de contexte « Upload as Text » sont disponibles, coller plus de 2 500 caractères dans le compositeur de message normal joint le texte sous forme de `pasted-text.txt` au lieu de remplir le champ de saisie. Les collages plus courts et ceux effectués sans la fonctionnalité `context` restent intégrés. Voir [Upload Files as Text](/docs/features/upload_as_text#paste-long-text-as-a-file).

**Collapse long user messages** est désactivé par défaut. Lorsqu'elle est activée, les messages utilisateur dépassant 256 pixels de hauteur s'affichent sous forme d'aperçu compact avec des commandes **Show more** et **Show less**. Le repliement est purement visuel : le message complet reste disponible pour la copie, la recherche dans le navigateur et les technologies d'assistance.

**L'analyse du LaTeX dans les messages** est activée par défaut. Le commutateur contrôle la forme mathématique en ligne ambiguë `$...$`, qui suit des règles de délimitation permettant de conserver le texte de type monétaire comme `$50` tel quel. Les formats mathématiques non ambigus `$$...$$`, `\(...\)` et `\[...\]` restent pris en charge lorsque le commutateur est désactivé. Le code en ligne, les blocs de code et les liens automatiques ne sont pas interprétés comme du LaTeX en ligne avec un seul dollar.

## Raccourcis clavier [#keyboard-shortcuts]

Ouvrez les **Keyboard Shortcuts** depuis le menu du compte pour consulter ou personnaliser les raccourcis. L'interrupteur **Keyboard Shortcuts** est activé par défaut. Le désactiver désactive tous les raccourcis et supprime les indications de raccourcis de l'interface tout en conservant les personnalisations. Ouvrez la même boîte de dialogue depuis le menu du compte pour réactiver les raccourcis.

L'activation des raccourcis et les combinaisons personnalisées sont stockées dans le navigateur actuel. Les lignes de combinaison restent visibles lorsque les raccourcis sont désactivés, mais les commandes de modification et de réinitialisation restent désactivées jusqu'à ce que les raccourcis soient à nouveau activés.

## Contrôles des données [#data-controls]

L'onglet **Data Controls** regroupe les actions de gestion des données personnelles en un seul endroit :

- **Manage files** ouvre le gestionnaire de fichiers téléchargés.
- **Importer des conversations** importe une exportation de conversation prise en charge.
- **Shared chats** répertorie et gère les liens de conversation publiés.
- **Provider API keys** gère les clés fournies pour les fournisseurs configurés.
- **Revoke all provider API keys** supprime toutes les clés de fournisseur fournies par l'utilisateur.
- **Default stateful workspace**, sous **Code execution**, sélectionne la portée de l'espace de travail proposée pour les nouveaux Agents créés. Il n'apparaît que lorsque les Stateful Code Sessions sont disponibles ; sa modification n'active pas les sessions avec état et ne modifie pas les Agents existants.
- **Delete TTS cache storage** supprime l'audio de synthèse vocale mis en cache dans le navigateur ; cette option est indisponible lorsque le cache est vide.
- **Archiver toutes les discussions** déplace les conversations actives vers **Discussions archivées** après confirmation, sans les supprimer.
- **Supprimer toutes les discussions** supprime définitivement les conversations de l'utilisateur après confirmation.

Les actions de suppression de données et de révocation de clés sont prises en charge par le serveur et peuvent être irréversibles. Les préférences et caches propres au navigateur s'appliquent au profil de navigateur actuel plutôt qu'à chaque appareil.
