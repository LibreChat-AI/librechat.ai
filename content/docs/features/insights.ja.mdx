Admin Insightsは、デプロイメントのプライマリMongoDBに保存されたLibreChatのアクティビティを確認するためのオプトイン形式のダッシュボードです。会話数、ユニークユーザー数、永続化されたメッセージ数、記録されたトークン数を時系列でレポートし、トップユーザー、チャーン（離脱）、最近の会話のビューを提供します。

## Insightsを有効にする [#enable-insights]

`.env` で `ENABLE_INSIGHTS=true` を設定し、LibreChat を再起動してください：

```sh filename=".env"
ENABLE_INSIGHTS=true
```

権限のあるアカウントに対して有効化されると、**Insights** がデスクトップのサイドバーおよびモバイルのパネルスイッチャーに表示されます。無効化されている場合、アクセスおよびデータルートは `404` を返し、ナビゲーション項目は非表示のままとなります。

## アクセス要件 [#access-requirements]

サインインしているアカウントは、以下の3つのチェックすべてを満たしている必要があります：

- `ADMIN` ロールを持つ
- `access:admin` システム権限を保持する
- `read:insights` システム権限を保持する

[Admin Panel](/docs/features/admin_panel) を使用して、システム機能を割り当てます。すべての Insights クエリは、認証された管理者からテナントスコープを導出します。テナント管理者は自身のテナントのレコードのみを表示でき、テナントを持たない管理者はスコープ設定されていないレコードのみを表示できます。

<Callout type="warning" title="機密性の高い運用データ">
  Insightsは、ユーザー名やメールアドレス、会話ID、および最近の会話の最初のメッセージを表示できます。`read:insights`権限は、これらのデータを確認する必要がある管理者にのみ付与してください。
</Callout>

## ダッシュボードメトリクス [#dashboard-metrics]

4つのサマリーメトリクスとそれらの日次スパークラインは、選択された日付範囲を使用します：

- **Conversations:** 指定された範囲内で作成された会話
- **ユニークユーザー:** 永続化されたメッセージアクティビティの一致によって識別されるユーザー
- **メッセージ:** ユーザーおよびアシスタントに帰属する、永続化されたユーザーメッセージとアシスタントメッセージ
- **トークン:** 記録されたメッセージの `tokenCount` 値の合計

ダッシュボードには以下も含まれています：

- **トップユーザー:** メッセージ数で順位付けされた最大8名のユーザー。各ユーザーの会話数とメッセージ数の合計が表示されます。
- **Churned users:** 選択した期間中に、アシスタントに送信された最新のメッセージから28日が経過したユーザー（最大8名）
- **最新の会話:** 日付、所有者、最初のメッセージ、永続化されたメッセージ数、および記録されたトークン数を含むページネーションされた会話

これらはデータベースのアクティビティメトリクスであり、課金やLangfuseの分析ではありません。トークンの合計はメッセージと共に永続化された値に依存しており、金銭的なコストを計算するものではありません。

## 日付範囲と検索 [#date-ranges-and-search]

デフォルトの範囲は7日間です。プリセットでは過去24時間、7日間、または30日間をカバーしています。カスタム範囲は最大で30暦日まで指定可能で、ブラウザの現在のタイムゾーンでグループ化されます。

最近の会話検索は、会話IDまたはユーザーIDと一致します。検索は3文字から開始され、最大200文字まで受け付けます。また、最新の会話テーブルは1ページあたり10行のページネーションが維持されます。サマリーカード、トップユーザー、およびチャーンメトリクスは、検索結果のサブセットではなく、選択された日付範囲を引き続き反映します。

## データとデプロイに関する注意点 [#data-and-deployment-notes]

Insightsは、既存のConversation、Message、およびUserコレクションを直接クエリするため、個別の分析用データベースを必要としません。結果には永続化されたレコードのみが反映されます。MongoDB内に存在しなくなった一時データや削除済みデータは表示されません。APIは、集計を実行する前に、カスタム範囲、結果リスト、ページサイズ、検索入力、およびテナントスコープを制限します。

デプロイメントのスイッチについては、[`ENABLE_INSIGHTS`](/docs/configuration/dotenv#admin-insights) を参照してください。
