<Callout type="info" title="Möchten Sie einfach direkt mit dem Chatten beginnen?">

Probieren Sie LibreChat jetzt direkt auf der kostenlosen öffentlichen Demo des Projekts unter [chat.librechat.ai](https://chat.librechat.ai) aus: Erstellen Sie dort ein Konto und beginnen Sie eine Unterhaltung. Die Demo dient nur zu Evaluierungszwecken und ist daher nicht der richtige Ort für private Daten oder Dinge, die Sie aufbewahren müssen ([Nutzungsbedingungen](/demo/terms), [Datenschutz](/demo/privacy)).

Für eine eigene Instanz installieren Sie LibreChat mit dem [Quick Start](/docs/quick_start) (etwa fünf Minuten mit Docker) und folgen dann [Your First Chat](/docs/quick_start/first_chat), um Ihr Konto zu erstellen, einen Modell-API-Schlüssel hinzuzufügen und Ihre erste Nachricht zu senden.

</Callout>

<Callout type="info" title="Suchen Sie nach einem Desktop-Installer?">

LibreChat ist eine selbst gehostete Webanwendung, keine native Windows-App oder Linux-AppImage. Verwenden Sie unter Windows [Docker Desktop](/docs/local/docker) für die einfachste lokale Einrichtung. Für Linux-Desktops oder -Server verwenden Sie [Docker](/docs/local/docker), [npm](/docs/local/npm) oder eine [Anleitung für Remote-Hosting](/docs/remote).

</Callout>
