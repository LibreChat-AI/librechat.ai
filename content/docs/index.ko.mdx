<Callout type="info" title="바로 채팅을 시작하고 싶으신가요?">

[chat.librechat.ai](https://chat.librechat.ai)에서 제공하는 프로젝트의 무료 공개 데모를 통해 지금 바로 LibreChat을 사용해 보세요. 계정을 생성하고 대화를 시작할 수 있습니다. 데모는 평가용으로만 제공되므로 개인 데이터나 보관이 필요한 정보를 입력하는 용도로는 적합하지 않습니다([이용 약관](/demo/terms), [개인정보 처리방침](/demo/privacy)).

자신만의 인스턴스를 사용하려면 [Quick Start](/docs/quick_start)를 통해 LibreChat을 설치하고(Docker를 사용하면 약 5분 소요), [Your First Chat](/docs/quick_start/first_chat)에 따라 계정을 생성한 뒤 모델 API 키를 추가하고 첫 메시지를 보내보세요.

</Callout>

<DocsHub />

<Callout type="info" title="데스크톱 설치 프로그램을 찾으시나요?">

LibreChat은 자체 호스팅 웹 애플리케이션이며, 네이티브 Windows 앱이나 Linux AppImage가 아닙니다. Windows에서는 가장 간단한 로컬 설정을 위해 [Docker Desktop](/docs/local/docker)을 사용하세요. Linux 데스크톱이나 서버의 경우 [Docker](/docs/local/docker), [npm](/docs/local/npm) 또는 [원격 호스팅 가이드](/docs/remote)를 사용하세요.

</Callout>
