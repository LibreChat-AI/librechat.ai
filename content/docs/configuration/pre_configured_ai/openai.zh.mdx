要获取您的 OpenAI API key，您需要：

- 前往 **[https://platform.openai.com/account/api-keys](https://platform.openai.com/account/api-keys)**
- 创建账户或使用现有账户登录
- 为您的账户添加付款方式
- 前往 https://platform.openai.com/api-keys 获取密钥。
- 您需要将以下环境变量设置为您的密钥，或者将其设置为 `user_provided` 以便用户提供他们自己的密钥。

```bash filename=".env"
OPENAI_API_KEY=user_provided
```

- 您可以使用 `OPENAI_MODELS` 来确定您希望可用的模型。
  - 当 `OPENAI_API_KEY` 设置为 `user_provided` 时 → 只有放入此列表中的模型才可用
    - ⚠️新模型不会自动显示；您需要先将它们添加到此列表中
  - 当 `OPENAI_API_KEY` 设置为实际的 API 密钥值时 → 只要 `OPENAI_MODELS` 保持注释状态，它就会进行 API 调用以查明哪些模型可用，这应该会包含任何新模型。

```bash filename=".env"
OPENAI_MODELS=gpt-5.6,gpt-5.6-terra,gpt-5.6-luna,gpt-5.5,gpt-5.5-pro,chat-latest,gpt-5.4,gpt-5.4-pro,gpt-5.4-mini,gpt-5.4-nano,gpt-5.3-codex,gpt-5.2,gpt-5,gpt-5-codex,gpt-5-mini,gpt-5-nano,o3-pro,o3,o4-mini,gpt-4.1,gpt-4.1-mini,gpt-4.1-nano,o3-mini,o1-pro,o1,gpt-4o,gpt-4o-mini
```

**注意：**

- 内部 OpenAI 默认模型包括 `gpt-5.6`、`gpt-5.6-terra` 和 `gpt-5.6-luna`，随后是现有的 GPT-5 目录。`gpt-5.6` 是 Sol 层级的别名；LibreChat 为所有三个 GPT-5.6 层级分配了 1,050,000 token 的上下文窗口和 128,000 token 的最大输出限制。已弃用的旧版默认模型不再包含在内，除非您通过 `OPENAI_MODELS` 显式添加它们。
- GPT-5.6 支持仅限 Responses API 的 `reasoning_mode` 值 `standard` 和 `pro`，以及 `reasoning_context` 值 `auto`、`current_turn` 和 `all_turns`。这些可以在 [model specs](/docs/configuration/librechat_yaml/object_structure/model_specs#reasoning_mode) 中进行配置。
- 对于具有非 `none` 的 `reasoning_effort` 的 GPT-5.6 模型，LibreChat 默认将规范的 OpenAI endpoint 指向 Responses API，以确保函数工具保持兼容。显式设置 `useResponsesApi: false` 则会保留使用 Chat Completions。Azure OpenAI、OpenRouter 以及自定义或反向代理的 base URL 不会自动切换。
- 当消息包含附件时，无需手动选择视觉模型，系统会在后台为您自动切换。如果您没有直接选择视觉模型，它将仅用于视觉请求；在请求成功后，您仍会看到您之前选择的非视觉模型。
- OpenAI Vision 模型允许在没有附件的情况下发送消息
- OpenAI endpoint 支持通过 `librechat.yaml` 配置文件使用所有 [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings)，包括 `streamRate`、`headers`、`titleModel`、`titleMethod`、`titlePrompt`、`titlePromptTemplate` 和 `titleEndpoint`。
