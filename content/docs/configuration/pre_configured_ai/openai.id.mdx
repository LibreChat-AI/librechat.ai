Untuk mendapatkan API key OpenAI Anda, Anda perlu:

- Buka **[https://platform.openai.com/account/api-keys](https://platform.openai.com/account/api-keys)**
- Buat akun atau masuk dengan akun yang sudah Anda miliki
- Tambahkan metode pembayaran ke akun Anda
- Buka https://platform.openai.com/api-keys untuk mendapatkan kunci.
- Anda perlu mengatur variabel lingkungan berikut ke kunci Anda, atau Anda dapat mengaturnya ke `user_provided` agar pengguna dapat menyediakan kunci mereka sendiri.

```bash filename=".env"
OPENAI_API_KEY=user_provided
```

<Callout type="info" title="Tempat pengguna memasukkan kunci mereka sendiri">

Dengan `user_provided`, Anda tidak perlu memberikan kunci sama sekali: setiap pengguna memasukkan kunci mereka sendiri dari UI obrolan. Buka menu endpoint, dan di samping **OpenAI** terdapat ikon roda gigi berlabel **Set API Key**. Mengkliknya akan membuka dialog dengan kolom untuk kunci tersebut dan menu tarik-turun untuk menentukan berapa lama kunci harus disimpan: 30 menit, 2 jam, 12 jam (default), 1 hari, 7 hari, 30 hari, atau tidak pernah kedaluwarsa.

Kunci tersebut dienkripsi dan disimpan di sisi server pada akun pengguna tersebut, sehingga kunci hanya perlu dimasukkan sekali, bukan per percakapan, dan tidak pernah dibagikan kepada pengguna lain. Dialog yang sama memiliki tindakan **Revoke** (Cabut), ditambah **Revoke All** (Cabut Semua) untuk menghapus setiap kunci yang telah disimpan oleh pengguna tersebut.

Jika menu endpoint disembunyikan, misalnya karena Model Specs menonaktifkan `modelSelect`, dialog yang sama dapat diakses dari **Settings** di bawah **Data controls**, pada bagian **API keys**.

Sampai pengguna menetapkan kunci, endpoint tersebut terlihat tetapi tidak dapat digunakan oleh mereka.

</Callout>

- Anda dapat menentukan model mana yang ingin Anda sediakan dengan `OPENAI_MODELS`
  - Ketika `OPENAI_API_KEY` diatur ke `user_provided` → hanya model yang dimasukkan ke dalam daftar ini yang akan tersedia
    - ⚠️Model baru tidak akan muncul secara otomatis; Anda harus menambahkannya ke daftar ini terlebih dahulu
  - Ketika `OPENAI_API_KEY` diatur ke nilai kunci API yang sebenarnya → selama `OPENAI_MODELS` dibiarkan dalam keadaan dikomentari (commented-out), sistem akan melakukan panggilan API untuk mengetahui model apa saja yang tersedia, yang seharusnya mencakup model baru apa pun.

```bash filename=".env"
OPENAI_MODELS=gpt-5.6,gpt-5.6-terra,gpt-5.6-luna,gpt-5.5,gpt-5.5-pro,chat-latest,gpt-5.4,gpt-5.4-pro,gpt-5.4-mini,gpt-5.4-nano,gpt-5.3-codex,gpt-5.2,gpt-5,gpt-5-codex,gpt-5-mini,gpt-5-nano,o3-pro,o3,o4-mini,gpt-4.1,gpt-4.1-mini,gpt-4.1-nano,o3-mini,o1-pro,o1,gpt-4o,gpt-4o-mini
```

**Catatan:**

- Default OpenAI internal mencakup `gpt-5.6`, `gpt-5.6-terra`, dan `gpt-5.6-luna`, diikuti oleh katalog GPT-5 yang sudah ada. `gpt-5.6` adalah alias tingkat Sol; LibreChat menetapkan jendela konteks 1.050.000 token dan output maksimum 128.000 token untuk ketiga tingkat GPT-5.6 tersebut. Default lama yang sudah tidak digunakan lagi tidak disertakan kecuali Anda menambahkannya secara eksplisit dengan `OPENAI_MODELS`.
- GPT-5.6 mendukung nilai `reasoning_mode` khusus Responses API yaitu `standard` dan `pro`, serta nilai `reasoning_context` yaitu `auto`, `current_turn`, dan `all_turns`. Pengaturan ini dapat dikonfigurasi di [model specs](/docs/configuration/librechat_yaml/object_structure/model_specs#reasoning_mode).
- Untuk model GPT-5.6 dengan `reasoning_effort` selain `none`, LibreChat secara default mengarahkan endpoint OpenAI kanonik ke Responses API agar alat fungsi (function tools) tetap kompatibel. Pengaturan eksplisit `useResponsesApi: false` akan tetap menggunakan Chat Completions. Azure OpenAI, OpenRouter, serta URL dasar kustom atau reverse-proxy tidak akan dialihkan secara otomatis.
- Memilih model vision untuk pesan dengan lampiran tidak diperlukan karena model tersebut akan dialihkan secara otomatis untuk Anda. Jika Anda tidak memilih model vision secara langsung, model tersebut hanya akan digunakan untuk permintaan vision dan Anda tetap akan melihat model non-vision yang telah Anda pilih setelah permintaan berhasil.
- Model OpenAI Vision memungkinkan pesan tanpa lampiran
- endpoint OpenAI mendukung semua [Shared Endpoint Settings](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings) melalui file konfigurasi `librechat.yaml`, termasuk `streamRate`, `headers`, `titleModel`, `titleMethod`, `titlePrompt`, `titlePromptTemplate`, dan `titleEndpoint`
