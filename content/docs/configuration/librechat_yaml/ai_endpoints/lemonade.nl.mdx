AMD Lemonade draait modellen lokaal via een OpenAI-compatibele API. Volg de [Lemonade documentation](https://lemonade-server.ai/docs/) om de server te installeren en te starten, en download vervolgens een chatmodel.

## Configuratie [#configuration]

Lemonade vereist geen API-sleutel; de onderstaande placeholder voldoet voor de OpenAI-client. Voeg het endpoint toe onder `endpoints.custom` in je `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Opmerkingen [#notes]

- Vervang `Qwen3-0.6B-GGUF` door een lokaal geïnstalleerd chatmodel. Met `fetch: true` haalt LibreChat de modellijst op van Lemonade. `titleModel: 'current_model'` hergebruikt het model van het gesprek voor titels.
- Voor Docker, vervang `localhost` door `host.docker.internal` of een bereikbare Lemonade-hostnaam.
- Voor door de gebruiker opgegeven basis-URL's, voeg de exacte `host:port` van de lokale server (bijv. `host.docker.internal:13305`) toe aan [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- Ingebouwde branding herkent `lemonade`, `AMD Lemonade` en `Lemonade Server`. Behoud `iconURL: 'lemonade'` om het logo te behouden bij het hernoemen van de endpoint.
