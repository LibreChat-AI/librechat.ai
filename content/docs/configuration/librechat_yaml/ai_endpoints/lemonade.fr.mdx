AMD Lemonade exécute des modèles localement via une API compatible avec OpenAI. Suivez la [documentation de Lemonade](https://lemonade-server.ai/docs/) pour installer et démarrer le serveur, puis téléchargez un modèle de chat.

## Configuration [#configuration]

Lemonade ne nécessite aucune clé API ; l'espace réservé ci-dessous satisfait le client OpenAI. Ajoutez l'endpoint sous `endpoints.custom` dans votre `librechat.yaml` :

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Notes [#notes]

- Remplacez `Qwen3-0.6B-GGUF` par un modèle de chat installé localement. Avec `fetch: true`, LibreChat récupère la liste des modèles depuis Lemonade. `titleModel: 'current_model'` réutilise le modèle de la conversation pour les titres.
- Pour Docker, remplacez `localhost` par `host.docker.internal` ou un nom d'hôte Lemonade accessible.
- Pour les URLs de base fournies par l'utilisateur, ajoutez le `host:port` exact du serveur local (par exemple `host.docker.internal:13305`) à [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- La personnalisation intégrée reconnaît `lemonade`, `AMD Lemonade` et `Lemonade Server`. Conservez `iconURL: 'lemonade'` pour préserver le logo lors du renommage de l'endpoint.
