AMD Lemonade menjalankan model secara lokal melalui API yang kompatibel dengan OpenAI. Ikuti [dokumentasi Lemonade](https://lemonade-server.ai/docs/) untuk menginstal dan memulai server, kemudian unduh model chat.

## Konfigurasi [#configuration]

Lemonade tidak memerlukan API key; placeholder di bawah ini memenuhi kebutuhan klien OpenAI. Tambahkan endpoint tersebut di bawah `endpoints.custom` dalam `librechat.yaml` Anda:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Catatan [#notes]

- Ganti `Qwen3-0.6B-GGUF` dengan model chat yang terinstal secara lokal. Dengan `fetch: true`, LibreChat mengambil daftar model dari Lemonade. `titleModel: 'current_model'` menggunakan kembali model percakapan untuk judul.
- Untuk Docker, ganti `localhost` dengan `host.docker.internal` atau nama host Lemonade yang dapat dijangkau.
- Untuk URL dasar yang disediakan pengguna, tambahkan `host:port` yang tepat dari server lokal (contoh: `host.docker.internal:13305`) ke [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- Branding bawaan mengenali `lemonade`, `AMD Lemonade`, dan `Lemonade Server`. Pertahankan `iconURL: 'lemonade'` untuk menjaga logo saat mengganti nama endpoint.
