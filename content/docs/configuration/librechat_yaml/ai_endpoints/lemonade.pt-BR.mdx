O AMD Lemonade executa modelos localmente através de uma API compatível com OpenAI. Siga a [documentação do Lemonade](https://lemonade-server.ai/docs/) para instalar e iniciar o servidor e, em seguida, baixe um modelo de chat.

## Configuração [#configuration]

Lemonade não requer uma chave de API; o placeholder abaixo satisfaz o cliente OpenAI. Adicione o endpoint em `endpoints.custom` no seu `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Notas [#notes]

- Substitua `Qwen3-0.6B-GGUF` por um modelo de chat instalado localmente. Com `fetch: true`, o LibreChat recupera a lista de modelos do Lemonade. `titleModel: 'current_model'` reutiliza o modelo da conversa para os títulos.
- Para Docker, substitua `localhost` por `host.docker.internal` ou um nome de host Lemonade acessível.
- Para URLs base fornecidas pelo usuário, adicione o `host:port` exato do servidor local (por exemplo, `host.docker.internal:13305`) em [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- A marca integrada reconhece `lemonade`, `AMD Lemonade` e `Lemonade Server`. Mantenha `iconURL: 'lemonade'` para preservar o logotipo ao renomear o endpoint.
