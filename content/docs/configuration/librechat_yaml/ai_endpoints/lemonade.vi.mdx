AMD Lemonade chạy các mô hình cục bộ thông qua một API tương thích với OpenAI. Hãy làm theo [tài liệu của Lemonade](https://lemonade-server.ai/docs/) để cài đặt và khởi động máy chủ, sau đó tải xuống một mô hình trò chuyện.

## Cấu hình [#configuration]

Lemonade không yêu cầu API key; phần giữ chỗ bên dưới đáp ứng yêu cầu của client OpenAI. Hãy thêm endpoint này vào mục `endpoints.custom` trong tệp `librechat.yaml` của bạn:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Ghi chú [#notes]

- Thay thế `Qwen3-0.6B-GGUF` bằng một mô hình trò chuyện được cài đặt cục bộ. Với `fetch: true`, LibreChat sẽ truy xuất danh sách mô hình từ Lemonade. `titleModel: 'current_model'` sử dụng lại mô hình của cuộc trò chuyện cho tiêu đề.
- Đối với Docker, hãy thay thế `localhost` bằng `host.docker.internal` hoặc một tên máy chủ Lemonade có thể truy cập được.
- Đối với các base URL do người dùng cung cấp, hãy thêm `host:port` chính xác của máy chủ cục bộ (ví dụ: `host.docker.internal:13305`) vào [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- Thương hiệu tích hợp nhận diện `lemonade`, `AMD Lemonade`, và `Lemonade Server`. Hãy giữ nguyên `iconURL: 'lemonade'` để bảo toàn logo khi đổi tên endpoint.
