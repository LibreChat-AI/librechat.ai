AMD Lemonade는 OpenAI 호환 API를 통해 로컬에서 모델을 실행합니다. [Lemonade documentation](https://lemonade-server.ai/docs/)을 따라 서버를 설치 및 시작한 다음, 채팅 모델을 다운로드하세요.

## 구성 [#configuration]

Lemonade는 API 키가 필요하지 않으며, 아래의 플레이스홀더가 OpenAI 클라이언트를 충족합니다. `librechat.yaml`의 `endpoints.custom` 아래에 해당 endpoint를 추가하세요:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## 참고 사항 [#notes]

- `Qwen3-0.6B-GGUF`를 로컬에 설치된 채팅 모델로 교체하세요. `fetch: true`를 설정하면 LibreChat이 Lemonade에서 모델 목록을 가져옵니다. `titleModel: 'current_model'`은 대화의 모델을 제목 생성에 재사용합니다.
- Docker의 경우, `localhost`를 `host.docker.internal` 또는 연결 가능한 Lemonade 호스트 이름으로 대체하세요.
- 사용자가 제공하는 베이스 URL의 경우, 로컬 서버의 정확한 `host:port`(예: `host.docker.internal:13305`)를 [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints)에 추가하세요.
- 내장된 브랜딩은 `lemonade`, `AMD Lemonade`, 그리고 `Lemonade Server`를 인식합니다. 엔드포인트 이름을 변경할 때 로고를 유지하려면 `iconURL: 'lemonade'`를 그대로 두십시오.
