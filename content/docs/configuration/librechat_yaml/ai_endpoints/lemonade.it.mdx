AMD Lemonade esegue modelli localmente tramite un'API compatibile con OpenAI. Segui la [documentazione di Lemonade](https://lemonade-server.ai/docs/) per installare e avviare il server, quindi scarica un modello di chat.

## Configurazione [#configuration]

Lemonade non richiede alcuna API key; il segnaposto sottostante soddisfa il client OpenAI. Aggiungi l'endpoint sotto `endpoints.custom` nel tuo `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Note [#notes]

- Sostituisci `Qwen3-0.6B-GGUF` con un modello di chat installato localmente. Con `fetch: true`, LibreChat recupera l'elenco dei modelli da Lemonade. `titleModel: 'current_model'` riutilizza il modello della conversazione per i titoli.
- Per Docker, sostituisci `localhost` con `host.docker.internal` o un hostname raggiungibile di Lemonade.
- Per gli URL di base forniti dall'utente, aggiungi l'esatto `host:port` del server locale (ad esempio `host.docker.internal:13305`) a [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- Il branding integrato riconosce `lemonade`, `AMD Lemonade` e `Lemonade Server`. Mantieni `iconURL: 'lemonade'` per preservare il logo quando rinomini l'endpoint.
