AMD Lemonadeは、OpenAI互換APIを通じてローカルでモデルを実行します。[Lemonade documentation](https://lemonade-server.ai/docs/)に従ってサーバーをインストールおよび起動し、チャットモデルをダウンロードしてください。

## 設定 [#configuration]

LemonadeはAPIキーを必要としませんが、以下のプレースホルダーがOpenAIクライアントの要件を満たします。`librechat.yaml`内の`endpoints.custom`に以下のエンドポイントを追加してください：

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## 注記 [#notes]

- `Qwen3-0.6B-GGUF` をローカルにインストールされたチャットモデルに置き換えます。`fetch: true` を設定すると、LibreChat は Lemonade からモデルリストを取得します。`titleModel: 'current_model'` は、タイトルの生成にその会話のモデルを再利用します。
- Dockerの場合は、`localhost` を `host.docker.internal` または到達可能なLemonadeのホスト名に置き換えてください。
- ユーザーが提供するベースURLについては、ローカルサーバーの正確な `host:port`（例: `host.docker.internal:13305`）を [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints) に追加してください。
- 組み込みのブランディングは `lemonade`、`AMD Lemonade`、および `Lemonade Server` を認識します。エンドポイントの名前を変更する際にロゴを保持するには、`iconURL: 'lemonade'` を維持してください。
