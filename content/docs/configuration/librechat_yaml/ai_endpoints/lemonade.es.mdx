AMD Lemonade ejecuta modelos localmente a través de una API compatible con OpenAI. Sigue la [documentación de Lemonade](https://lemonade-server.ai/docs/) para instalar e iniciar el servidor, luego descarga un modelo de chat.

## Configuración [#configuration]

Lemonade no requiere una API key; el marcador de posición a continuación satisface al cliente de OpenAI. Añada el endpoint bajo `endpoints.custom` en su `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Notas [#notes]

- Reemplace `Qwen3-0.6B-GGUF` con un modelo de chat instalado localmente. Con `fetch: true`, LibreChat recupera la lista de modelos desde Lemonade. `titleModel: 'current_model'` reutiliza el modelo de la conversación para los títulos.
- Para Docker, reemplace `localhost` con `host.docker.internal` o un nombre de host de Lemonade accesible.
- Para las URLs base proporcionadas por el usuario, añade el `host:port` exacto del servidor local (por ejemplo, `host.docker.internal:13305`) a [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- La marca integrada reconoce `lemonade`, `AMD Lemonade` y `Lemonade Server`. Mantenga `iconURL: 'lemonade'` para conservar el logotipo al renombrar el endpoint.
