Cheaper Inference is an OpenAI-compatible gateway.
It serves models from OpenAI, Anthropic, Google, DeepSeek and other labs, below the list price of each lab.

## Get an API key

Create a key in [Cheaper Inference](https://cheaperinference.com/docs#api-keys) and add it to your `.env` file:

```bash filename=".env"
CHEAPER_INFERENCE_API_KEY=your-api-key
```

## Configuration

Add the endpoint under `endpoints.custom` in your `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: "Cheaper Inference"
      apiKey: "${CHEAPER_INFERENCE_API_KEY}"
      baseURL: "https://api.cheaperinference.com/v1"
      models:
        default: ["gpt-5.4"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"
      modelDisplayLabel: "Cheaper Inference"
```

## Notes

- With `fetch: true`, LibreChat loads the model list from `/v1/models`. The `default` array is only the first selection.
- Some models in the list are not chat models, for example image and video models. Select a chat model.
- Billing is prepaid. An empty wallet causes HTTP 402 errors.
