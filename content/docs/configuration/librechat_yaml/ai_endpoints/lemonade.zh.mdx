AMD Lemonade 通过兼容 OpenAI 的 API 在本地运行模型。请遵循 [Lemonade documentation](https://lemonade-server.ai/docs/) 安装并启动服务器，然后下载一个聊天模型。

## 配置 [#configuration]

Lemonade 不需要 API 密钥；下方的占位符可满足 OpenAI 客户端的要求。请在 `librechat.yaml` 中的 `endpoints.custom` 下添加该 endpoint：

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## 注意事项 [#notes]

- 将 `Qwen3-0.6B-GGUF` 替换为本地安装的聊天模型。设置 `fetch: true` 后，LibreChat 将从 Lemonade 获取模型列表。`titleModel: 'current_model'` 会复用对话的模型来生成标题。
- 对于 Docker，请将 `localhost` 替换为 `host.docker.internal` 或可访问的 Lemonade 主机名。
- 对于用户提供的 base URL，请将本地服务器确切的 `host:port`（例如 `host.docker.internal:13305`）添加到 [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints) 中。
- 内置品牌识别功能支持 `lemonade`、`AMD Lemonade` 和 `Lemonade Server`。重命名 endpoint 时，请保留 `iconURL: 'lemonade'` 以维持图标显示。
