AMD Lemonade, OpenAI uyumlu bir API aracılığıyla modelleri yerel olarak çalıştırır. Sunucuyu kurmak ve başlatmak için [Lemonade documentation](https://lemonade-server.ai/docs/) kısmını takip edin, ardından bir sohbet modeli indirin.

## Yapılandırma [#configuration]

Lemonade herhangi bir API anahtarı gerektirmez; aşağıdaki yer tutucu OpenAI istemcisini karşılar. Uç noktayı `librechat.yaml` dosyanızdaki `endpoints.custom` altına ekleyin:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Notlar [#notes]

- `Qwen3-0.6B-GGUF` ifadesini yerel olarak kurulu bir sohbet modeliyle değiştirin. `fetch: true` ile LibreChat, model listesini Lemonade'den alır. `titleModel: 'current_model'` ise başlıklar için konuşmanın modelini yeniden kullanır.
- Docker için `localhost` ifadesini `host.docker.internal` veya erişilebilir bir Lemonade ana bilgisayar adı (hostname) ile değiştirin.
- Kullanıcı tarafından sağlanan temel URL'ler için, yerel sunucunun tam `host:port` bilgisini (örneğin `host.docker.internal:13305`) [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints) kısmına ekleyin.
- Yerleşik markalama `lemonade`, `AMD Lemonade` ve `Lemonade Server` ifadelerini tanır. Uç noktayı yeniden adlandırırken logoyu korumak için `iconURL: 'lemonade'` ifadesini olduğu gibi tutun.
