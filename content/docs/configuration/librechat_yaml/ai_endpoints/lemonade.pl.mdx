AMD Lemonade uruchamia modele lokalnie za pośrednictwem API zgodnego z OpenAI. Postępuj zgodnie z [dokumentacją Lemonade](https://lemonade-server.ai/docs/), aby zainstalować i uruchomić serwer, a następnie pobierz model czatu.

## Konfiguracja [#configuration]

Lemonade nie wymaga klucza API; poniższy symbol zastępczy spełnia wymagania klienta OpenAI. Dodaj endpoint w sekcji `endpoints.custom` w swoim `librechat.yaml`:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Uwagi [#notes]

- Zastąp `Qwen3-0.6B-GGUF` lokalnie zainstalowanym modelem czatu. Dzięki `fetch: true`, LibreChat pobiera listę modeli z Lemonade. `titleModel: 'current_model'` ponownie wykorzystuje model konwersacji do generowania tytułów.
- W przypadku Docker, zastąp `localhost` przez `host.docker.internal` lub osiągalną nazwę hosta Lemonade.
- W przypadku adresów URL bazowych dostarczonych przez użytkownika, dodaj dokładny `host:port` lokalnego serwera (np. `host.docker.internal:13305`) do [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints).
- Wbudowany branding rozpoznaje `lemonade`, `AMD Lemonade` oraz `Lemonade Server`. Zachowaj `iconURL: 'lemonade'`, aby zachować logo podczas zmiany nazwy endpoint.
