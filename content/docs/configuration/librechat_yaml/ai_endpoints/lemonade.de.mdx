AMD Lemonade führt Modelle lokal über eine OpenAI-kompatible API aus. Befolgen Sie die [Lemonade documentation](https://lemonade-server.ai/docs/), um den Server zu installieren und zu starten, und laden Sie anschließend ein Chat-Modell herunter.

## Konfiguration [#configuration]

Lemonade benötigt keinen API-Schlüssel; der untenstehende Platzhalter genügt für den OpenAI-Client. Fügen Sie den endpoint unter `endpoints.custom` in Ihrer `librechat.yaml` hinzu:

```yaml filename="librechat.yaml"
    - name: 'lemonade'
      apiKey: 'lemonade'
      baseURL: 'http://localhost:13305/v1'
      models:
        default: ['Qwen3-0.6B-GGUF']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'AMD Lemonade'
      iconURL: 'lemonade'
```

## Hinweise [#notes]

- Ersetzen Sie `Qwen3-0.6B-GGUF` durch ein lokal installiertes Chat-Modell. Mit `fetch: true` ruft LibreChat die Modellliste von Lemonade ab. `titleModel: 'current_model'` verwendet das Modell der Konversation für Titel wieder.
- Ersetzen Sie für Docker `localhost` durch `host.docker.internal` oder einen erreichbaren Lemonade-Hostnamen.
- Für vom Benutzer bereitgestellte Basis-URLs fügen Sie den exakten `host:port` des lokalen Servers (z. B. `host.docker.internal:13305`) zu [`endpoints.allowedAddresses`](/docs/configuration/librechat_yaml/object_structure/config#endpoints) hinzu.
- Das integrierte Branding erkennt `lemonade`, `AMD Lemonade` und `Lemonade Server`. Behalten Sie `iconURL: 'lemonade'` bei, um das Logo beim Umbenennen des endpoint beizubehalten.
