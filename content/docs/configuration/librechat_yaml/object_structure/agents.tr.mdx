Bu sayfa [`agents`](/docs/features/agents) endpoint'i için geçerlidir.

## Örnek [#example]

```yaml filename="Agents Endpoint"
endpoints:
  agents:
    recursionLimit: 50
    maxRecursionLimit: 100
    maxSubagents: 20
    maxToolCallArgBytes: 65536
    maxDeltaEventsPerTurn: 100000
    maxToolCallArgBytesByTool:
      create_file: 131072
    disableBuilder: false
    # (optional) Agent Capabilities available to all users. Omit the ones you wish to exclude. Defaults to list below.
    # Opt-in capabilities: "programmatic_tools", "stateful_code_sessions", "run_in_background", and "tool_intents".
    # capabilities: ["deferred_tools", "execute_code", "file_search", "web_search", "artifacts", "subagents", "actions", "context", "skills", "memory", "ask_user_question", "tools", "chain", "ocr"]
    # (optional) File citation configuration for file_search capability
    maxCitations: 30 # Maximum total citations in responses (1-50)
    maxCitationsPerFile: 7 # Maximum citations from each file (1-10)
    minRelevanceScore: 0.45 # Minimum relevance score threshold (0.0-1.0)
    titleTiming: immediate
    activityLabel: true
    activityModel: gpt-4.1-nano
    activityPhaseLabel: true
    activityPhaseMaxPerRun: 5
    skills:
      maxCatalogSkills: 20
    statefulCodeSessions:
      allowedEnvironments: ['user', 'agent-user', 'conversation']
      environments:
        - id: managed-default
          name: Managed Code API
          type: managed
          baseURL: https://code.example.com/v1
          default: true
        - id: engineering-vm
          name: Engineering VM
          type: attached
          baseURL: https://code-bridge.example.com/v1
          pairing:
            workerId: engineering-vm
            tokenEnv: CODE_BRIDGE_ADMIN_TOKEN
        - id: personal-workers
          name: Personal Code Workers
          type: attached
          baseURL: https://code-bridge.example.com/v1
          pairing:
            allowPrincipalWorkers: true
            tokenEnv: CODE_BRIDGE_ADMIN_TOKEN
    # eventDriven:
    #   selfUrl: https://librechat.internal
    backgroundTasks:
      completionWakeups: true
    toolApproval:
      enabled: true
      mode: default
      deny: ['mcp:*:delete_*']
      ask: ['mcp:*:*']
    checkpointer:
      type: mongo
      ttl: 86400
    remoteApi:
      auth:
        oidc:
          enabled: false
```

> Bu yapılandırma, ajanlar için oluşturucu arayüzünü etkinleştirir.

## Akış devre kesicileri [#stream-circuit-breakers]

Bu ayarlar, bir sağlayıcı akışı kontrolden çıkmış araç argümanları veya sınırsız bir delta olayları dizisi üretiyor gibi göründüğünde bir Agent çalışmasını durdurur.

<OptionTable
  options={[
    [
      'maxToolCallArgBytes',
      'Number',
      'Bir akışlı araç çağrısının argümanları için maksimum kümülatif bayt sayısı. Genel korumayı devre dışı bırakmak için 0 olarak ayarlayın.',
      '65536',
    ],
    [
      'maxDeltaEventsPerTurn',
      'Number',
      'Bir model oluşturma turu için maksimum akış etkinliği. Bu korumayı devre dışı bırakmak için 0 olarak ayarlayın veya boş bırakın.',
      '0 (disabled)',
    ],
    [
      'maxToolCallArgBytesByTool',
      'Object',
      'Modelin gördüğü araç adına göre anahtarlanmış araç bazlı argüman bayt geçersiz kılmaları. 0 değeri, o araç için korumayı devre dışı bırakır.',
      'create_file: 131072',
    ],
  ]}
/>

LibreChat, 64 KiB'lık bir genel argüman sınırı kullanır ve `create_file` için 128 KiB'lık bir geçersiz kılma (override) ile gelir; çünkü bu işlevin meşru yükleri genellikle daha büyüktür. `maxToolCallArgBytesByTool` içindeki girdiler, bu yerleşik geçersiz kılma ile birleşir. Korumalardan herhangi biri tetiklenirse, LibreChat devam eden sağlayıcı akışını durdurur ve hangi sınırın aşıldığını bildirir.

```yaml filename="endpoints / agents / stream circuit breakers"
maxToolCallArgBytes: 65536
maxDeltaEventsPerTurn: 100000
maxToolCallArgBytesByTool:
  create_file: 262144
  large_import: 524288
```

Her bir argüman boyutu korumasını devre dışı bırakmak için hem genel sınırı hem de gönderilen `create_file` geçersiz kılmasını `0` olarak ayarlayın:

```yaml
maxToolCallArgBytes: 0
maxToolCallArgBytesByTool:
  create_file: 0
```

## activityLabel

Her bir Ajan muhakemesi ve araç çağrısı bloğunu oluşturulan tek satırlık bir başlık altında gruplamak için `activityLabel: true` olarak ayarlayın. Ek model çağrısını ve maliyetini kontrol etmek için `activityModel`, `activityEndpoint`, `activityPrompt`, `activityMaxPerRun` ve `activityCharLimit` seçeneklerini kullanın. Tam alan referansı ve öncelik kuralları için [Agent Activity Groups](/docs/configuration/librechat_yaml/object_structure/shared_endpoint_settings#agent-activity-groups) bölümüne bakın.

```yaml filename="endpoints / agents / activity groups"
activityLabel: true
activityEndpoint: openAI
activityModel: gpt-4.1-nano
activityMaxPerRun: 20
activityCharLimit: 600
activityPhaseLabel: true
activityPhaseMaxPerRun: 5
```

`activityPhaseLabel`, en az iki mantıksal etkinlik içeren her bir çalıştırma aşamasının etrafına bağımsız olarak bir daraltılmış üst özet ekleyebilir. Bu çağrıları ayarlamak için `activityPhaseModel`, `activityPhaseEndpoint`, `activityPhasePrompt` ve `activityPhaseMaxPerRun` kullanın; `activityCharLimit` alt etkinlik etiketleriyle paylaşılır.

## capabilities

<OptionTable
  options={[
    [
      'capabilities',
      'Array/List of Strings',
      'Agents endpoint\'i için tüm kullanıcılara sunulan agent yeteneklerini belirtir.',
      'Defines the agent capabilities that are available to all users for the agents endpoint. You can omit the capabilities you wish to exclude from the list.',
    ],
  ]}
/>

**Varsayılan:** `["deferred_tools", "execute_code", "file_search", "web_search", "artifacts", "subagents", "actions", "context", "skills", "memory", "ask_user_question", "tools", "chain", "ocr"]`

`programmatic_tools`, `stateful_code_sessions`, `run_in_background` ve `tool_intents` isteğe bağlıdır ve açıkça eklenmelidir. Programmatic tools ve stateful sessions ayrıca `execute_code` ve uyumlu bir Code Interpreter dağıtımı gerektirir. Agent Builder, Code Interpreter olmadan Programmatic MCP seçimlerini devre dışı bırakır ve sunucu, kod yürütme özelliği mevcut olmadığında eski programmatic caller seçeneklerini kaldırır. `run_in_background`, Code Interpreter araçlarını varsayılan olarak uygun hale getirir ve uygun MCP, Plugin ve Action araçları için araç bazında katılıma izin verir; arka planda kod yürütme işlemi de `execute_code` ve Code Interpreter gerektirir.

`stateful_code_sessions` oldukça deneyseldir. [`LIBRECHAT_CODE_BASEURL_STATEFUL`](/docs/configuration/dotenv#stateful-code-interpreter-endpoint) veya [`statefulCodeSessions.environments`](#statefulcodesessions) ile yapılandırılmış ayrı bir `stateful` profilli Code Interpreter rotası gerektirir. Stateful istekler, normal stateless hizmete geri dönmek yerine başarısız olur. Agent Builder içinde, etkinleştirilen her Agent; kullanıcı, ajan-ve-kullanıcı veya konuşma çalışma alanı kapsamını ve adlandırılmış arka uçlar yapılandırıldığında bir yürütme ortamını seçer. Yeni Agent'lar, kullanıcının kişisel kapsam varsayılanı ve dağıtımın varsayılan yürütme ortamı ile başlar.

**Örnek:**

```yaml filename="endpoints / agents / capabilities"
capabilities:
  - 'deferred_tools'
  # Optional: enables Programmatic Tool Calling for MCP tools marked Programmatic in the Agent Builder.
  # Requires execute_code and a Code Interpreter deployment with the Tool Call Server component.
  # - 'programmatic_tools'
  - 'execute_code'
  - 'file_search'
  - 'web_search'
  - 'artifacts'
  - 'subagents'
  - 'actions'
  - 'context'
  - 'skills'
  - 'memory'
  - 'ask_user_question'
  - 'tools'
  - 'chain'
  - 'ocr'
  # Optional and highly experimental: reuse a user-, agent-and-user-, or
  # conversation-scoped workspace. Requires LIBRECHAT_CODE_BASEURL_STATEFUL
  # or a named statefulCodeSessions environment.
  # - 'stateful_code_sessions'
  # Optional: allow eligible Code Interpreter, MCP, Plugin, and Action tools to run as background tasks.
  # - 'run_in_background'
  # Optional: show live model-written intent labels for native and selected MCP tools.
  # - 'tool_intents'
```

**Not:** Bu alan isteğe bağlıdır. Atlanırsa, varsayılan davranış, varsayılan değerde listelenen tüm yetenekleri dahil etmektir.

## statefulCodeSessions

Son derece deneysel durum bilgili (stateful) Code Interpreter çalışma alanları için paylaşım kapsamlarını ve isteğe bağlı yürütme arka uçlarını yapılandırır.

<Callout type="warning" title="Son derece deneysel">
  Stateful Code Sessions, adlandırılmış yürütme ortamları, bağlı çalışanlar (attached workers) ve eşleştirme (pairing) özellikleri erken deneme aşamasındadır. Bunların davranışları, yapılandırmaları, kalıcılık özellikleri ve entegrasyon protokolleri önemli ölçüde değişebilir.
</Callout>

<OptionTable
  options={[
    [
      'allowedEnvironments',
      'Array/List of Strings',
      'İzin verilen durum bilgili çalışma alanı kapsamları: `user`, `agent-user` ve/veya `conversation`.',
      '["user", "agent-user", "sohbet"]',
    ],
    [
      'environments',
      'Array of Objects',
      'Agent Builder\'da gösterilen isteğe bağlı adlandırılmış yönetilen veya ekli Code API ortamları.',
      'Unset; LIBRECHAT_CODE_BASEURL_STATEFUL remains the stateful endpoint',
    ],
  ]}
/>

```yaml filename="endpoints / agents / statefulCodeSessions"
statefulCodeSessions:
  allowedEnvironments:
    - 'user'
    - 'agent-user'
    - 'conversation'
  environments:
    - id: managed-default
      name: Managed Code API
      type: managed
      baseURL: https://code.example.com/v1
      default: true
    - id: engineering-vm
      name: Engineering VM
      type: attached
      baseURL: https://code-bridge.example.com/v1
      owner: deployment
      pairing:
        workerId: engineering-vm
        tokenEnv: CODE_BRIDGE_ADMIN_TOKEN
    - id: personal-workers
      name: Personal Code Workers
      type: attached
      baseURL: https://code-bridge.example.com/v1
      owner: deployment
      configSchema:
        permissions:
          fileWrite:
            allowed: [allow, ask, deny]
            default: ask
          commandExecution:
            allowed: [ask, deny]
            default: ask
      pairing:
        allowPrincipalWorkers: true
        tokenEnv: CODE_BRIDGE_ADMIN_TOKEN
```

`allowedEnvironments`, blok mevcut olduğunda gereklidir ve en az bir çalışma alanı kapsamı (workspace scope) içermelidir. Üç kapsamın tamamına izin vermek ve durum bilgisi olan (stateful) işleri [`LIBRECHAT_CODE_BASEURL_STATEFUL`](/docs/configuration/dotenv#stateful-code-interpreter-endpoint) üzerinden yönlendirmeye devam etmek için bloğun tamamını atlayın. Kişisel varsayılan ve Agent Builder yalnızca izin verilen değerlere izin verir. Bir yönetici politikayı sıkılaştırırsa, kaydedilmiş bir kişisel varsayılan görünür kalır ancak devre dışı bırakılır ve yeni Agent'lar izin verilen ilk kapsamı kullanır. Mevcut etkinleştirilmiş Agent'lar kaydedilmiş kapsamlarını korurlar, ancak artık izin verilmeyen bir kapsam, Agent yeniden yapılandırılana kadar çalışma zamanında başarısız olur.

`environments` boş olmadığında, her giriş benzersiz bir `id`, bir görünen `name`, `managed` veya `attached` şeklinde bir `type` ve sorgu dizisi ya da fragman içermeyen bir HTTP(S) `baseURL` gerektirir. Liste çalıştırılabilir ortamlar içeriyorsa, bu girişlerden tam olarak bir tanesi `default: true` olarak ayarlanmalıdır. Agent Builder daha sonra bir **Execution environment** seçicisi ekler; bunu **Deployment default** üzerinde bırakmak, söz konusu varsayılan girişi kullanır. Yalnızca self-servis eşleştirme kontrol düzlemlerini içeren bir liste varsayılan değer gerektirmez. Daha sonra kaldırılan veya artık erişilemeyen bir ortamı adlandıran bir Agent, başka bir arka uca geri dönmek yerine başarısız olur (fail closed).

- `managed` doğrudan operatör tarafından yönetilen durum bilgisi olan (stateful) bir Code API'sine işaret eder.
- `attached`, işi bir dış `@librechat/code` çalışanına kiralayan uyumlu bir Code API `remote-bridge` arka ucunu işaret eder. Çalışan, gelen bir genel bağlantı noktası gerektirmez, ancak yerel yürütme endpoint'inin yine de uygun yalıtıma ihtiyacı vardır.
- `workerId`, isteğe bağlı olarak ekli bir ortamı tek bir giden çalışana (outbound worker) yönlendirir. Yalnızca sunucu tarafında çalışır ve istemci başlatma yapılandırması aracılığıyla dışa aktarılmaz.
- `owner` varsayılan olarak `deployment` değerini alır. Principal sahipli ortamlar, LibreChat'in kimlik doğrulamalı Code Environments API'si aracılığıyla oluşturulur, ACL'ler ile korunur ve yalnızca yetkili istekler için birleştirilir; istemci tarafından sağlanan URL'leri deployment YAML dosyasına yerleştirmeyin.
- `pairing` isteğe bağlıdır ve yalnızca dağıtımın sahip olduğu `attached` girdileri için geçerlidir. `pairing.workerId`, kaydedilecek operatör yönetimindeki bir çalışanı tanımlarken, `pairing.allowPrincipalWorkers: true` yetkili kullanıcıların sahip tabanlı çalışanları bu kontrol düzlemine kaydetmesine olanak tanır. `pairing` mevcut olduğunda bu alanlardan en az birinin girilmesi zorunludur.
- `pairing.tokenEnv`, köprü yöneticisi belirtecini içeren ortam değişkenini adlandırır; asla belirtecin kendisini içermez. Eşleştirme, loopback geliştirme haricinde HTTPS gerektirir.
- `configSchema.permissions`, yetkili sahiplerin **Ayarlar > Kod ortamları** altında kişisel ortamlar için `fileWrite` ve `commandExecution` politikasını isteğe bağlı olarak seçmelerine olanak tanır. Her alan, `allow`, `ask` ve/veya `deny` içeren boş olmayan bir `allowed` listesi gerektirir; `default` değeri atlandığında `ask` olarak kabul edilir ve `allowed` listesinde yer almalıdır. LibreChat, yönetici listesinin dışındaki kayıtlı değerleri reddeder.
- `settings` kısmını deployment YAML dosyasında yapılandırmayın. LibreChat, bu istek kapsamlı alanı, kimliği doğrulanmış sahibin sunucu tarafından doğrulanmış tercihlerinden sağlar.
- Yalnızca dosya yazma ve komut yürütme ilkesi kullanıcı tarafından yapılandırılabilir. İzolasyon, ağ oluşturma, bağlamalar (mounts), ayrıcalıklı yürütme, giriş (ingress), çıkış (egress) ve gizli anahtarlar (secrets) yönetici kontrolünde kalmaya devam eder.
- Hem üst düzey `workerId` hem de `pairing.workerId` mevcutsa, bunların birbiriyle eşleşmesi gerekir. `allowPrincipalWorkers: true` değerine sahip ve her iki worker ID'si de yalnızca eşleştirme (pairing-only) olmayan bir girdi: yürütme seçicilerinden çıkarılır ve `default: true` olarak ayarlanamaz.

Ekli yürütme, otomatik olarak güvenli bir onay temeli sağlar: dosya yazma ve komut veya kod yürütme işlemleri onay isterken, salt okunur ve arama işlemleri normal araç politikası kapsamında devam eder. Temel, ekli ortamı kullanan Agent ile sınırlandırılmıştır. Kullanıcı ayarı mevcut değilse, LibreChat `ask` kullanır; [`toolApproval.enabled: false`](#toolapproval), bu ekli ortam temelini devre dışı bırakan yönetici acil durum geçersiz kılma ayarıdır. Onay ve devam ettirme desteği olmayan çağrılar, bu açık geçersiz kılma ayarlanmadığı sürece başarısız olur.

Ekli yürütme, eşleşen bir deneysel Code Interpreter remote-bridge yapısı gerektirir. Eşleştirme, giden worker bağlantısının kimliğini doğrular; sandbox veya VM izolasyonunun yerini almaz. Code Environment yönetimi iznine sahip kullanıcılar, **Ayarlar > Kod ortamları** altında eşleştirme yapabilir, izin verilen araç politikasını yapılandırabilir ve kişisel worker'ları iptal edebilir. Bkz. [Stateful Code Sessions](/docs/features/code_interpreter#stateful-code-sessions).

## eventDriven

Ajan olay iletimi tarafından kullanılan güvenilir dahili kaynağı yapılandırır. Çoğu dağıtım bu bloğu atlamalı ve mevcut sürecin bağlı dinleyicisini kullanmalıdır.

<OptionTable
  options={[
    [
      'selfUrl',
      'URL',
      'Güvenilir dahili tetikleyici kabulü için mevcut işleme bağlı dinleyiciyi geçersiz kılar. Yalnızca teslimatın başka bir güvenilir HTTP kaynağından geçmesi gerektiğinde kullanın.',
      '',
    ],
  ]}
/>

```yaml filename="endpoints / agents / eventDriven"
endpoints:
  agents:
    eventDriven:
      selfUrl: https://librechat.internal
```

Bağlı alt devamlılıklar (bound child continuations) otomatiktir. `eventDriven` altındaki eski `childTurns`, `completionWakeups`, `coalescing`, `actorMailbox`, `checkpointForks` ve `durableReceipts` alanları artık yapılandırma anahtarları değildir ve kaldırılmalıdır. Çalışma zamanı (runtime) artık bu teslimat garantilerini doğrudan uygulamaktadır. Ayrı olan [`backgroundTasks.completionWakeups`](#backgroundtasks) alanı, tamamlanmış arka plan araçları ve ayrılmış Subagent'lar için konuşma teslimatını kontrol eder.

Normal bağlı dinleyici yolu için `selfUrl` değerini boş bırakın. Bunu yalnızca güvenilir dahili tetikleyici kabulünün, bir TLS ön kapısı gibi başka bir HTTP(S) kaynağından geçmesi gerektiğinde ayarlayın. `AGENT_TRIGGERS_SELF_URL`, bu alanın belirtilmediği durumlarda bir uyumluluk yedeği olarak kalmaya devam eder. Bkz. [Agents API events](/docs/features/agents_api#agent-events) ve [Automatic Parent Continuation](/docs/features/subagents#automatic-parent-continuation).

Event Actor detached Action tamamlanması, yerleşik üretim deposundan otomatik olarak seçilir. Bellek içi yürütme işlem yerelidir; Redis üretim akışları, dayanıklı yeniden başlatma kurtarma ve kopya devri ekler. Herhangi bir `librechat.yaml` anahtarı veya ortam özellik bayrağı gerekmez. Bkz. [Agent Event Runtime](/docs/configuration/dotenv#agent-event-runtime).

## backgroundTasks

Desteklenen tamamlanmış arka plan araçlarının ve ayrılmış Subagent'ların, kaydedilmiş üst Agent'larını otomatik olarak devam ettirip ettirmeyeceğini kontrol eder.

<OptionTable
  options={[
    [
      'completionWakeups',
      'Boolean',

Desenler glob eşleştirmesi kullanır. MCP araçları `mcp:<server>:<tool>` ile kapsamlandırılabilir; örneğin, `mcp:github:*` ifadesi `github` sunucusundaki her araçla eşleşir. LibreChat, statik kuralları ve kanca eşleştiricilerini (hook matchers), iç içe geçmiş Subagent'lar aracılığıyla ulaşılabilen araçlar da dahil olmak üzere, MCP çalışma zamanı adlarına ve model odaklı takma adlara uygular. Statik kurallar, seçilen mod geri dönüşü (fallback) sağlamadan önce `deny`, `ask` ve ardından `allow` sırasıyla değerlendirilir. Bu nedenle, `bypass` modu da dahil olmak üzere, bir engelleme (deny) kuralı her zaman önceliklidir.

```yaml filename="endpoints / agents / toolApproval"
toolApproval:
  enabled: true
  mode: default
  allow:
    - 'mcp:analytics:read_*'
  deny:
    - 'mcp:*:delete_*'
  ask:
    - 'mcp:*:*'
  reason: 'Review {tool} before it runs.'
```

Hooks, sunucu başlatıldığında bir kez yüklenir ve LibreChat sürecinde çalıştırılır. Her girdi bir `module`, isteğe bağlı bir araç adı `matcher` regex'i ve modülün oluşturucusuna iletilen isteğe bağlı bir `options` nesnesi kabul eder. Yalnızca güvendiğiniz kodları yükleyin. Role veya kiracı bazlı geçersiz kılmalar (overrides) hook modüllerini yeniden yüklemez; bağlamsal davranışı hook içinde uygulayın.

```yaml filename="endpoints / agents / toolApproval / hooks"
toolApproval:
  enabled: true
  hooks:
    - module: '@acme/librechat-approval-hook'
      matcher: '^mcp:production:'
      options:
        requireTicket: true
```

Dağıtım, ondan fazla alt öğeye yetki vermesi gereken orkestrasyon ağırlıklı aracılar çalıştırdığında bunu yükseltin. Değer başlangıçta okunur ve üç yerde uygulanır:

</Callout>

<Callout type="note">
  Sınır, süreç genelindedir ve `librechat.yaml` dosyasından gelir. `endpoints.agents.maxSubagents` için kullanıcı veya grup bazlı bir veritabanı geçersiz kılma işlemi, sunulan yapılandırmaya yansıtılır ancak istek doğrulama tarafından uygulanmaz.
</Callout>

## Ajan Yetenekleri [#agent-capabilities]

`capabilities` alanı, aracılar için belirli işlevleri etkinleştirmenize veya devre dışı bırakmanıza olanak tanır. Mevcut yetenekler şunlardır:

- **deferred_tools**: Temsilcilerin, her aracı önceden bağlama yüklemek yerine çalışma zamanında ertelenmiş MCP araçlarını keşfetmesine olanak tanır.
- **programmatic_tools**: Agent Builder'da Programmatic olarak işaretlenmiş MCP araçları için Programmatic Tool Calling özelliğini etkinleştirir. `execute_code` ve Tool Call Server bileşenine sahip bir Code Interpreter dağıtımı gerektirir. Bu yetenek isteğe bağlıdır (opt-in) ve varsayılan olarak etkin değildir.
- **execute_code**: Ajanın kod çalıştırmasına izin verir.
- **stateful_code_sessions**: Seçili temsilcilerin bir Code Interpreter çalışma alanını kullanıcı, temsilci-ve-kullanıcı veya konuşma kapsamında yeniden kullanmasına olanak tanır. `execute_code`, uyumlu bir Code Interpreter dağıtımı ve temsilci bazlı Gelişmiş ayar gerektirir. Yeni Temsilciler, oturum açmış kullanıcının tercih ettiği kapsamı kullanır. Bu yetenek oldukça deneyseldir, varsayılan olarak etkin değildir ve deneme sürecinde önemli ölçüde değişebilir; mevcut davranışını veya yapılandırmasını kararlı bir üretim sözleşmesi olarak değerlendirmeyin.
- **file_search**: Ajanın dosyaları aramasını ve dosyalarla etkileşime girmesini sağlar. Etkinleştirildiğinde, alıntı davranışı `maxCitations`, `maxCitationsPerFile` ve `minRelevanceScore` ayarlarıyla kontrol edilir.
- **web_search**: Temsilciler için web arama işlevini etkinleştirir, internetten bilgi aramalarına ve almalarına olanak tanır.
- **artifacts**: Ajanın etkileşimli artifact'ler (React bileşenleri, HTML, Mermaid diyagramları) oluşturmasını sağlar.
- **subagents**: İzole edilmiş bağlamlı alt ajan çalıştırmalarını etkinleştirir. Bkz. [Subagents](/docs/features/subagents).
- **actions**: Ajanın önceden tanımlanmış eylemleri gerçekleştirmesine izin verir.
- **context**: Sohbet içinde "Metin Olarak Yükle" işlevini ve aracılar için "Dosya Bağlamı" özelliğini etkinleştirir; bu, kullanıcıların dosya yüklemesine ve içeriklerinin ayıklanarak doğrudan konuşmaya dahil edilmesine olanak tanır.
- **skills**: Yan panelde Skills özelliğini, manuel `$` çağrısını, model tarafından çağrılan skills özelliklerini ve aracı skill izin listelerini etkinleştirir. Bkz. [Skills](/docs/features/skills).
- **memory**: Bellek yapılandırıldığında ve kullanıcının erişimi olduğunda, aracıların `set_memory` ve `delete_memory` kullanmasına olanak tanır. Varsayılan olarak etkindir; bellek devre dışı bırakıldığında çalışma zamanında kaldırılır.
- **ask_user_question**: Temsilcilerin tek bir formda bir ila dört arası ilgili soru sormak için duraklamasına ve yanıtlarla devam etmesine olanak tanır. Varsayılan olarak etkindir.
- **tools**: Ajanın çeşitli araçlara erişimini sağlar.
- **chain**: Ajan zincirleme (Mixture-of-Agents (MoA) iş akışları olarak da bilinir) için Beta özelliğini etkinleştirir.
- **ocr**: Sohbet içinde "Metin Olarak Yükle" özelliğini ve aracılar için "Dosya Bağlamı"nı isteğe bağlı olarak geliştirir; dosyaların yüklenmesine ve OCR ile işlenmesine olanak tanır. **Bir OCR hizmetinin yapılandırılmasını gerektirir.**
- **run_in_background**: Code Interpreter yürütmesini ve kabuk araçlarını varsayılan olarak arka planda çalışmaya uygun hale getirir ve uygun MCP, Plugin ve Action araçları için araç bazında arka plan katılımını etkinleştirir. Action düzeyindeki bir anahtar, uygun olan her işlemi dahil eder; OAuth Action'ları ve halihazırda bir `run_in_background` parametresi tanımlayan işlemler hariç tutulur. Bir ajan, Code Interpreter'ı açıkça devre dışı bırakabilir. Bu ayar arka planda yürütmeye izin verir; model, her çağrıda bunu kullanıp kullanmayacağına karar verir. `execute_code` ve kod için yapılandırılmış bir Code Interpreter dağıtımı gerektirir. Bu özellik varsayılan olarak etkin değildir.
- **tool_intents**: Uygun araç çağrılarına canlı model yazımı niyet etiketleri ekler. Kod Yorumlayıcı araçları dahil olmak üzere yerel araçlar otomatik olarak dahil olur; MCP araçları, Agent Builder içinde tek tek veya toplu olarak etkinleştirilebilir. Model specs, `describeIntent` kullanır. Bu özellik varsayılan olarak etkin değildir.

Yetenekleri belirterek, kullanıcıların temsilcilerle etkileşim kurarken erişebilecekleri özellikleri kontrol edebilirsiniz.

## Örnek Yapılandırma [#example-configuration]

Aşağıda, `agents` endpoint'ini özel yetenekler ve dosya alıntı ayarlarıyla yapılandırmaya dair bir örnek bulunmaktadır:

```yaml filename="Agents Endpoint"
endpoints:
  agents:
    disableBuilder: false
    # File citation configuration
    maxCitations: 20
    maxCitationsPerFile: 5
    minRelevanceScore: 0.6
    # Custom capabilities
    capabilities:
      # Optional: enables Programmatic Tool Calling for MCP tools marked Programmatic in the Agent Builder.
      # - 'programmatic_tools'
      - 'execute_code'
      # Optional: makes Code Interpreter background-eligible and enables selected MCP, Plugin, and Action tools.
      # - 'run_in_background'
      # Optional: enables live intent labels for native and selected MCP tools.
      # - 'tool_intents'
      - 'file_search'
      - 'skills'
      - 'subagents'
      - 'actions'
      - 'artifacts'
      - 'context'
      - 'ocr'
      - 'web_search'
```

Bu örnekte:

- Oluşturucu arayüzü etkinleştirildi
- Dosya alıntıları toplamda 20 ile sınırlıdır ve dosya başına en fazla 5 alıntı yapılabilir.
- Yalnızca %60 ve üzeri uygunluğa sahip kaynaklar dahil edilir
- LibreChat Ajanları; kod yürütme, dosya arama (alıntılarla birlikte), Yetenekler (Skills), Alt ajanlar (Subagents), eylemler (actions), yapıtlar (artifacts), dosya bağlamı, yapılandırılmışsa OCR hizmetleri ve web arama yeteneklerine erişebilir.
- `execute_code` ile birlikte `programmatic_tools` yeteneğini eklemediğiniz sürece Programmatic Tool Calling devre dışı kalmaya devam eder.
- Arka plan araç çağrıları, `run_in_background` eklemediğiniz sürece devre dışı kalmaya devam eder; Code Interpreter araçları varsayılan olarak uygun hale gelirken, uygun MCP, Plugin ve Action araçları hala seçim gerektirir.
- `tool_intents` eklemediğiniz sürece araç amacı etiketleri devre dışı kalır; yerel araçlar otomatik olarak dahil olurken, MCP araçları hala araç bazında seçim gerektirir.

**Örnek - Sadece OIDC:**

```yaml filename="endpoints / agents / remoteApi"
endpoints:
  agents:
    remoteApi:
      auth:
        apiKey:
          enabled: false
        oidc:
          enabled: true
          issuer: https://auth.example.com/realms/myrealm
          audience: my-client-id
```

**Örnek - API anahtarı yedeği ile OIDC:**

```yaml filename="endpoints / agents / remoteApi"
endpoints:
  agents:
    remoteApi:
      auth:
        apiKey:
          enabled: true
        oidc:
          enabled: true
          issuer: https://auth.example.com/realms/myrealm
          # jwksUri is optional and auto-discovered if omitted
          jwksUri: https://auth.example.com/realms/myrealm/protocol/openid-connect/certs
          audience: my-client-id
```

<Callout type="info">
  JWKS URI çözümleme önceliği sırasıyla açıkça belirtilen `jwksUri`, ardından `OPENID_JWKS_URL` ve son olarak `{issuer}/.well-known/openid-configuration` üzerinden otomatik keşiftir.
</Callout>

<Callout type="info">
  OIDC kullanıcı eşleştirme, birincil arama için `sub` claim'ini kullanır; `email`, `preferred_username` veya `upn` claim'leri ise yedek olarak kullanılır. Eşleşen kullanıcının LibreChat içinde zaten mevcut olması gerekir.
</Callout>

Ekip tanımları bağlantılı bir yönlü döngüsüz çizge (DAG) oluşturmalı, her üye kullanıcı tarafından görülebilir olmalı ve toplam yapılandırma 50 benzersiz Agent hedefi ve 100 genişletilmiş çalışma yapılandırması ile sınırlandırılmıştır. ## Notlar [#notes]

- [modelSpecs](/docs/configuration/librechat_yaml/object_structure/model_specs) kullanarak seçim yapılabilecek bir temsilci listesi tanımlamadığınız sürece builder arayüzünü devre dışı bırakmanız önerilmez.
- Dosya alıntı yapılandırması (`maxCitations`, `maxCitationsPerFile`, `minRelevanceScore`) yalnızca `file_search` özelliği etkinleştirildiğinde geçerlidir.
- Alaka düzeyi puanı, 1.0'ın mükemmel bir eşleşmeyi, 0.0'ın ise hiç benzerlik olmadığını temsil ettiği vektör benzerliği kullanılarak hesaplanır.
- Alıntı sınırları, kapsamlı bilgi erişimi ile yanıt kalitesi ve performans arasında denge kurmaya yardımcı olur.
- `context` yeteneği, metin ayrıştırma yöntemlerini kullanarak OCR yapılandırması olmadan çalışır. OCR yapılandırıldığında, çıkarma kalitesini artırır.
- `ocr` yeteneği, bir OCR hizmetinin yapılandırılmasını gerektirir (bkz. [OCR Yapılandırması](/docs/configuration/librechat_yaml/object_structure/ocr)).
- `maxSubagents`, tek bir ajanın referans verebileceği alt ajan sayısını sınırlar. Bu, [Subagents](/docs/features/subagents#limits) altında belgelenen derinlik veya grafik sınırlarını değiştirmez.
