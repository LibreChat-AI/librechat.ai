Halaman ini menjelaskan pengaturan konfigurasi bersama untuk semua endpoint. Pengaturan yang disorot di sini tersedia untuk semua konfigurasi di bawah kolom ["Endpoints"](/docs/configuration/librechat_yaml/object_structure/config#endpoints) kecuali dinyatakan sebaliknya.

## Contoh Konfigurasi [#example-configuration]

```yaml filename="Shared Endpoint Settings"
endpoints:
  # Individual endpoint configurations
  openAI:
    streamRate: 25
    titleModel: 'gpt-4o-mini'
    titleMethod: 'completion'
    titleTiming: 'immediate'
    titlePrompt: "Create a concise title for this conversation:\n\n{convo}"
    headers:
      X-Gateway-Metadata: '{"user_email":"{{LIBRECHAT_USER_EMAIL}}"}'

  azureOpenAI:
    streamRate: 35
    titleModel: 'grok-3'
    titleMethod: 'structured'
    titlePrompt: |
      Analyze this conversation and provide:
      1. A concise title in the detected language (5 words or less, no punctuation or quotation)
      2. Always provide a relevant emoji at the start of the title

      {convo}
    titleConvo: true

  anthropic:
    streamRate: 25
    titleModel: 'claude-3-5-haiku-20241022'
    titleMethod: 'completion'
    headers:
      X-Conversation-Id: '{{LIBRECHAT_BODY_CONVERSATIONID}}'

  bedrock:
    streamRate: 25
    titleModel: 'us.amazon.nova-lite-v1:0'
    titleEndpoint: 'anthropic'

  google:
    streamRate: 25
    titleModel: 'gemini-2.0-flash-lite'
    titlePromptTemplate: "Human: {input}\nAssistant: {output}"
    headers:
      X-Gateway-Metadata: '{"user_id":"{{LIBRECHAT_USER_ID}}"}'

  assistants:
    streamRate: 30

  azureAssistants:
    streamRate: 30

  agents:
    activityLabel: true
    activityEndpoint: 'openAI'
    activityModel: 'gpt-4.1-nano'
    activityMaxPerRun: 20
    activityCharLimit: 600
    activityPhaseLabel: true
    activityPhaseMaxPerRun: 5

  # Global configuration using 'all' - this applies shared settings across endpoints.
  # Most defined values override endpoint defaults; headers are merged and endpoint values win on collisions.
  all:
    headers:
      X-App: 'librechat'
    titleConvo: true
    titleModel: 'gpt-4.1-nano'
    titleTiming: 'immediate'
    titlePrompt: |
      Analyze this conversation and provide:
      1. The detected language of the conversation
      2. A concise title in the detected language (5 words or less, no punctuation or quotation)
      3. Always provide a relevant emoji at the start of the title
      {convo}
```

> **Penting:** Saat menggunakan konfigurasi `all`, sebagian besar properti bersama yang Anda tentukan akan berlaku di seluruh endpoint. Pada contoh di atas, konfigurasi `all` akan menerapkan `titleConvo`, `titleModel`, dan `titlePrompt` ke semua endpoint, sementara pengaturan `streamRate` individu akan tetap dipertahankan karena tidak didefinisikan di dalam `all`. `headers` digabungkan secara terpisah: nilai dari `endpoints.all.headers` berlaku secara global, dan header tingkat endpoint akan diutamakan jika terjadi tabrakan kunci (key collisions). Pengaturan aktivitas diselesaikan per kolom dengan urutan yang sama, sehingga pengaturan `all` yang tidak terkait tidak akan menyembunyikan konfigurasi aktivitas suatu endpoint.

## streamRate

**Kunci:**

<OptionTable
  options={[
    [
      'streamRate',
      'Number',
      'Kecepatan data dialirkan dari endpoint. Berguna untuk mengontrol laju streaming data.',
      'streamRate: 25',
    ],
  ]}
/>

**Default:** Bergantung pada penyedia. OpenAI, endpoint kustom, Anthropic, Google, Bedrock, dan stream yang didukung Agents SDK menggunakan *adaptive smoothing* dengan target 25 ms. Penangan Legacy Assistants dan Ollama mempertahankan perilaku per-chunk penyedia mereka, dengan default 1 ms.

Penghalusan adaptif (adaptive smoothing) memancarkan token teks pertama tanpa penundaan, meningkatkan ukuran potongan (chunk) saat aliran tertinggal, serta menjaga urutan pemanggilan alat (tool-call) dan metadata. Atur `streamRate` ke target milidetik non-negatif; `streamRate: 0` menonaktifkan penghalusan adaptif pada penyedia berbasis SDK yang tercantum di atas.

Nilai khusus endpoint dipertahankan ketika `endpoints.all` ada tanpa `streamRate`. Mendefinisikan `endpoints.all.streamRate` akan menimpa nilai endpoint, termasuk `0` yang eksplisit.

## titleConvo

**Kunci:**

<OptionTable
  options={[
    [

/>

**Default:** `false`

**Catatan:**

- Saat diaktifkan, judul akan dibuat secara otomatis menggunakan pengaturan judul yang telah dikonfigurasi
- Harus digunakan bersama dengan `titleModel` atau endpoint tersebut harus memiliki model default yang tersedia

**Contoh:**

```yaml filename="titleConvo"
titleConvo: true
```

## titleTiming

**Kunci:**

<OptionTable
  options={[
    [
      'titleTiming',
      'String',
      'Mengontrol kapan judul percakapan dibuat. Nilai yang valid: "immediate" atau "final".',
      'titleTiming: "immediate"',
    ],
  ]}
/>

**Default:** `"immediate"`

**Nilai yang Tersedia:**

- **`"immediate"`** - Menghasilkan judul segera setelah permintaan dimulai, secara paralel dengan respons model, menggunakan pesan pertama pengguna. Judul biasanya muncul dalam satu atau dua detik.
- **`"final"`** - Menunda pembuatan judul hingga respons penuh selesai. Ini mempertahankan perilaku lama.

**Contoh:**

```yaml filename="titleTiming"
endpoints:
  all:
    titleTiming: 'immediate'
```

## titleMethod

**Kunci:**

<OptionTable
  options={[
    [
      'titleMethod',
      'String',
      'Mengontrol metode yang digunakan untuk membuat judul percakapan.',
      'Valid values: "completion" (default), "structured", "functions" (legacy alias for "structured")',
    ],
  ]}
/>

**Default:** `"completion"`

**Metode yang Tersedia:**

- **`"completion"`** - Menggunakan API penyelesaian standar tanpa alat/fungsi. Kompatibel dengan sebagian besar LLM.
- **`"structured"`** - Menggunakan output terstruktur untuk pembuatan judul. Memerlukan dukungan penyedia/model.
- **`"functions"`** - Alias lama untuk "structured". Secara fungsional identik.

**Contoh:**

```yaml filename="titleMethod"
titleMethod: 'completion'
```

**Kunci:**

<OptionTable

## titleEndpoint

**Kunci:**

<OptionTable
  options={[
    [
      'titleEndpoint',

      'Allows using a different, potentially cheaper model/endpoint for titles.',

**Default:** Menggunakan endpoint percakapan saat ini

**Nilai yang Diterima:**

- `openAI`
- `azureOpenAI`
- `google`
- `anthropic`

```yaml filename="titleEndpoint"
# Use Anthropic for titles even when chatting with OpenAI
endpoints:

    # Will use anthropic's configuration for title generation
```

## Grup Aktivitas Agen [#agent-activity-groups]

Grup aktivitas membuat eksekusi Agen yang panjang lebih mudah dipindai dengan melipat setiap blok penalaran dan pemanggilan alat yang berurutan di bawah satu header satu baris yang dibuat secara otomatis. Pembuatan header berjalan di luar jalur respons model utama, namun tetap merupakan panggilan model dan penggunaannya akan dicatat serta ditagihkan.

Dengan label fase induk diaktifkan, teks progres singkat tetap berada di dalam fase aktif. Sebuah fase ditutup sebelum teks jawaban substansial agar hasilnya tetap berada di luar ringkasan yang diciutkan, dan blok penalaran atau panggilan alat (tool calls) berikutnya dapat memulai fase lain dalam proses yang sama. LibreChat juga melakukan rebase pada batas fase yang disimpan ketika konten yang cacat atau dihilangkan dipadatkan, sehingga menjaga penyelarasannya setelah dimuat ulang.

```yaml filename="endpoints / agents / activity groups"
endpoints:
  agents:
    activityLabel: true
    activityEndpoint: 'openAI'
    activityModel: 'gpt-4.1-nano'
    activityMaxPerRun: 20
    activityCharLimit: 600
    activityPhaseLabel: true
    activityPhaseMaxPerRun: 5
```

Anda juga dapat mengatur kolom-kolom ini di bawah `endpoints.all` atau penyedia pendukung/endpoint kustom. Nilai diselesaikan secara independen, dengan nilai yang didefinisikan pertama yang akan digunakan sesuai urutan berikut: `endpoints.all`, endpoint `agents` publik, kemudian penyedia pendukung atau endpoint kustom. Jika `activityEndpoint` tidak diketahui, LibreChat akan mencatat peringatan dan menggunakan penyedia Agen tersebut sebagai gantinya.

Ringkasan fase induk tidak bergantung pada label aktivitas anak: `activityPhaseLabel` dapat diaktifkan dengan atau tanpa `activityLabel`. LibreChat hanya menggunakan satu panggilan model ringkasan fase untuk fase yang berisi setidaknya dua aktivitas logis. `activityCharLimit` juga membatasi bukti yang digunakan untuk ringkasan fase. Pemilihan model fase diselesaikan melalui `activityPhaseModel`, `activityModel`, `titleModel` dari endpoint asal, kemudian model yang sedang berjalan; pemilihan endpoint fase diselesaikan melalui `activityPhaseEndpoint`, `activityEndpoint`, kemudian penyedia Agent. Endpoint fase yang dikonfigurasi namun tidak diketahui akan mencatat peringatan dan kembali ke penyedia Agent.

## headers

**Kunci:**

<OptionTable
  options={[
    [
      'headers',
      'Object/Dictionary',
      'Header permintaan kustom diteruskan ke endpoint penyedia bawaan yang didukung.',
      'Useful for AI gateways and reverse proxies that consume metadata headers while LibreChat keeps provider-native request formatting.',
    ],
  ]}
/>

**Endpoint yang didukung:** `openAI`, `anthropic`, `google`, dan `all`.

**Contoh:**

```yaml filename="endpoints / headers"
endpoints:
  all:
    headers:
      X-App: 'librechat'
  anthropic:
    headers:
      X-Conversation-Id: '{{LIBRECHAT_BODY_CONVERSATIONID}}'
```

**Catatan:**

- Nilai mendukung `${ENV_VAR}`, `{{LIBRECHAT_USER_*}}`, dan placeholder request-body seperti `{{LIBRECHAT_BODY_CONVERSATIONID}}`.
- Pada langkah resolusi keluar terakhir, placeholder pengguna, badan-permintaan, dan OpenID yang dikenali tanpa nilai akan menjadi string kosong alih-alih diteruskan sebagai teks templat. Nama placeholder yang tidak dikenal akan tetap tidak berubah sehingga kesalahan pengetikan konfigurasi dapat terlihat.
- Header tingkat endpoint akan menimpa `endpoints.all.headers` jika terjadi tabrakan kunci.
- Otentikasi yang dikelola penyedia dan header beta/protokol yang diperlukan tetap menjadi otoritas. Nilai beta Anthropic digabungkan sehingga flag beta kustom tidak menimpa flag penyedia yang diperlukan.
- Header juga diteruskan untuk permintaan model-list penyedia yang didukung.
- Gunakan header metadata di balik gateway atau reverse proxy yang mengonsumsinya. API penyedia asli biasanya mengabaikan header yang tidak dikenal.

---

**Catatan:**

- Semua pengaturan yang ditampilkan di halaman ini dapat dikonfigurasi secara individual per endpoint atau secara global menggunakan kunci `all`
- Saat menggunakan konfigurasi `all`, pengaturan tersebut akan menimpa pengaturan yang sesuai di SEMUA endpoint individual.
- Kunci `all` tidak menerima `baseURL`
- Pengaturan yang tidak didefinisikan dalam `all` akan mempertahankan nilai endpoint individunya masing-masing
- Untuk `streamRate`: Nilai antara 25-40 direkomendasikan jika penghalusan (smoothing) spesifik endpoint diinginkan
- Menggunakan tingkat stream yang lebih tinggi adalah suatu keharusan saat melayani aplikasi untuk banyak pengguna dalam skala besar

**Contoh Perilaku Override:**

```yaml
endpoints:
  openAI:
    streamRate: 25 # This will be preserved
    titleModel: 'gpt-4' # This will be overridden
    titleConvo: false # This will be overridden

  all:
    titleConvo: true
    titleModel: 'gpt-3.5-turbo'
    # streamRate not defined here, so individual values are kept
```
