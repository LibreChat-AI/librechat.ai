## Langkah 1: Buat Aplikasi SAML di Auth0 [#step-1-create-a-saml-application-in-auth0]

1. Masuk ke Auth0 Dashboard Anda.
2. Navigasikan ke `Applications > Applications`.
3. Klik `Create Application`.
4. Masukkan Nama Aplikasi (contoh: `LibreChat`) dan pilih `Regular Web Application`.
5. Klik `Create`.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## Langkah 2: Konfigurasi Add-On SAML [#step-2-configure-the-saml-add-on]

1. Buka aplikasi yang baru dibuat di Auth0.
2. Buka tab `Addons`.
3. Klik penggeser untuk mengaktifkan `SAML2 Web App`.
4. Klik panel `SAML2 Web App`.
5. Konfigurasikan pengaturan berikut:
   - **Application Callback URL**: Atur ini ke URL callback SAML LibreChat Anda:
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **Pengaturan (Format JSON)**: Gunakan konfigurasi berikut:
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="Audience harus cocok dengan SAML_ISSUER">
        Atur `audience` ke string yang sama dengan yang akan Anda gunakan untuk `SAML_ISSUER` di Langkah 4.
        Jangan lewatkan bagian ini karena Auth0 akan menetapkan audience default-nya sendiri, yang tidak akan cocok dengan apa yang dikirimkan oleh LibreChat, sehingga proses login akan gagal karena ketidakcocokan audience.
        </Callout>
        <Callout type="note" title="catatan">
        Jika aplikasi Anda memerlukan atribut tambahan seperti `given_name`, `family_name`, `username`, atau `picture`, pastikan pemetaan ini dikonfigurasi dengan benar di pengaturan SAML Auth0.
        </Callout>
6. Klik `Save`.

## Langkah 3: Dapatkan Metadata SAML Auth0 [#step-3-obtain-the-auth0-saml-metadata]

1. Setelah SAML diaktifkan, kembali ke pengaturan `SAML2 Web App`.
2. Buka tab `Usage`.
3. Klik `Identity Provider Certificate: Download Auth0 certificate`.
4. Gunakan `Identity Provider Login URL` untuk `SAML_ENTRY_POINT`.
5. Gunakan `Issuer` untuk `SAML_IDP_ISSUER` (opsional, lihat keterangan di bawah).
6. Salin file sertifikat yang telah diunduh ke folder proyek Anda.

<Callout type="warning" title="SAML_ISSUER adalah milik Anda, bukan milik Auth0">

`SAML_ISSUER` adalah ID entitas yang **dikirimkan LibreChat mengenai dirinya sendiri** dalam permintaan autentikasinya, bukan nilai yang Anda salin dari Auth0. Anda yang memilihnya, dan nilai ini harus berupa string yang sama dengan yang Anda masukkan di sisi Auth0 sebagai **Audience**. URL dasar LibreChat Anda adalah pilihan yang konvensional:

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

Nilai `Issuer` milik Auth0 dimasukkan ke dalam variabel `SAML_IDP_ISSUER` yang terpisah, yang digunakan oleh LibreChat untuk memeriksa apakah sebuah assertion benar-benar berasal dari penyedia identitas Anda.

LibreChat tidak menerbitkan dokumen metadata SAML, jadi tidak ada URL metadata yang dapat diberikan ke Auth0. Konfigurasikan Auth0 secara manual dengan Audience di atas dan callback URL di bawah.

</Callout>

## Langkah 4: Konfigurasi LibreChat dengan SAML [#step-4-configure-librechat-with-saml]

Buka file `.env` di folder proyek Anda dan tambahkan variabel berikut:

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
