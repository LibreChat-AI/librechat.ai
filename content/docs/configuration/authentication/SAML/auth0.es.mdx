## Paso 1: Crear una aplicación SAML en Auth0 [#step-1-create-a-saml-application-in-auth0]

1. Inicia sesión en tu Auth0 Dashboard.
2. Navega a `Applications > Applications`.
3. Haz clic en `Create Application`.
4. Ingrese un Application Name (por ejemplo, `LibreChat`) y seleccione `Regular Web Application`.
5. Haz clic en `Create`.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## Paso 2: Configurar el complemento SAML [#step-2-configure-the-saml-add-on]

1. Abre la aplicación recién creada en Auth0.
2. Ve a la pestaña `Addons`.
3. Haz clic en el control deslizante para habilitar la `SAML2 Web App`.
4. Haz clic en el panel `SAML2 Web App`.
5. Configure los siguientes ajustes:
   - **Application Callback URL**: Establézcalo en su URL de callback SAML de LibreChat:
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **Configuración (Formato JSON)**: Utilice la siguiente configuración:
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="Audience debe coincidir con SAML_ISSUER">
        Establezca `audience` con la misma cadena que utilizará para `SAML_ISSUER` en el Paso 4.
        Si la omite, Auth0 establecerá su propia audiencia predeterminada, la cual no coincidirá
        con lo que LibreChat envía, y el inicio de sesión fallará debido a una discrepancia de audiencia.
        </Callout>
        <Callout type="note" title="nota">
        Si su aplicación requiere atributos adicionales como `given_name`, `family_name`, `username` o `picture`, asegúrese de que estas asignaciones estén configuradas correctamente en la configuración SAML de Auth0.
        </Callout>
6. Haz clic en `Save`.

## Paso 3: Obtener los metadatos SAML de Auth0 [#step-3-obtain-the-auth0-saml-metadata]

1. Una vez que SAML esté habilitado, regrese a la configuración de `SAML2 Web App`.
2. Ve a la pestaña `Usage`.
3. Haz clic en `Identity Provider Certificate: Download Auth0 certificate`.
4. Utilice la `Identity Provider Login URL` para `SAML_ENTRY_POINT`.
5. Utilice el `Issuer` para `SAML_IDP_ISSUER` (opcional, consulte la nota a continuación).
6. Copia el archivo de certificado descargado a la carpeta de tu proyecto.

<Callout type="warning" title="SAML_ISSUER es el suyo, no el de Auth0">

`SAML_ISSUER` es el ID de entidad que **LibreChat envía sobre sí mismo** en sus solicitudes de autenticación, no un valor que copias desde Auth0. Tú lo eliges, y es la misma cadena que ingresas en el lado de Auth0 como **Audience**. Tu URL base de LibreChat es la elección convencional:

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

El valor `Issuer` propio de Auth0 se coloca en la variable independiente `SAML_IDP_ISSUER`, la cual LibreChat utiliza para verificar que una aserción provenga realmente de su proveedor de identidad.

LibreChat no publica un documento de metadatos SAML, por lo que no hay una URL de metadatos para proporcionar a Auth0. Configure Auth0 manualmente con la Audience anterior y la URL de callback a continuación.

</Callout>

## Paso 4: Configurar LibreChat con SAML [#step-4-configure-librechat-with-saml]

Abra el archivo `.env` en la carpeta de su proyecto y añada las siguientes variables:

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
