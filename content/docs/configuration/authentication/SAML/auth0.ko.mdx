## 1단계: Auth0에서 SAML 애플리케이션 생성하기 [#step-1-create-a-saml-application-in-auth0]

1. Auth0 Dashboard에 로그인하세요.
2. `Applications > Applications`로 이동합니다.
3. `Create Application`을 클릭하세요.
4. 애플리케이션 이름(예: `LibreChat`)을 입력하고 `Regular Web Application`을 선택하세요.
5. `Create`를 클릭하세요.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## 2단계: SAML 애드온 구성 [#step-2-configure-the-saml-add-on]

1. Auth0에서 새로 생성된 애플리케이션을 엽니다.
2. `Addons` 탭으로 이동하세요.
3. 슬라이더를 클릭하여 `SAML2 Web App`을 활성화하세요.
4. `SAML2 Web App` 패널을 클릭하세요.
5. 다음 설정을 구성하세요:
   - **Application Callback URL**: LibreChat SAML 콜백 URL로 설정하세요:
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **설정 (JSON 형식)**: 다음 구성을 사용하세요:
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="Audience는 SAML_ISSUER와 일치해야 합니다">
        `audience`를 4단계에서 `SAML_ISSUER`로 사용할 문자열과 동일하게 설정하세요.
        이 설정을 생략하면 Auth0가 자체 기본 audience를 주장하게 되는데, 이는 LibreChat이 보내는 값과 일치하지 않아 audience 불일치로 인해 로그인이 실패하게 됩니다.
        </Callout>
        <Callout type="note" title="참고">
        애플리케이션에 `given_name`, `family_name`, `username` 또는 `picture`와 같은 추가 속성이 필요한 경우, 이러한 매핑이 Auth0 SAML 설정에서 올바르게 구성되었는지 확인하십시오.
        </Callout>
6. `Save`를 클릭하세요.

## 3단계: Auth0 SAML 메타데이터 획득 [#step-3-obtain-the-auth0-saml-metadata]

1. SAML이 활성화되면 `SAML2 Web App` 설정으로 돌아가십시오.
2. `Usage` 탭으로 이동하세요.
3. `Identity Provider Certificate: Download Auth0 certificate`를 클릭하세요.
4. `SAML_ENTRY_POINT`에 `Identity Provider Login URL`을 사용하세요.
5. `SAML_IDP_ISSUER`에는 `Issuer`를 사용하세요(선택 사항, 아래의 주의 사항 참조).
6. 다운로드한 cert 파일을 프로젝트 폴더로 복사하세요.

<Callout type="warning" title="SAML_ISSUER는 Auth0의 것이 아닌 귀하의 것입니다">

`SAML_ISSUER`는 Auth0에서 복사하는 값이 아니라, **LibreChat이 인증 요청 시 자신에 대해 보내는** 엔티티 ID입니다. 이 값은 직접 선택하며, Auth0 측에 **Audience**로 입력하는 문자열과 동일해야 합니다. LibreChat 기본 URL을 사용하는 것이 일반적입니다:

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

Auth0의 `Issuer` 값은 별도의 `SAML_IDP_ISSUER` 변수에 입력하며, LibreChat은 이를 사용하여 어설션(assertion)이 실제로 귀하의 ID 공급자로부터 온 것인지 확인합니다.

LibreChat은 SAML 메타데이터 문서를 게시하지 않으므로, Auth0에 제공할 메타데이터 URL이 없습니다. 위에서 언급한 Audience와 아래의 콜백 URL을 사용하여 Auth0를 수동으로 구성하십시오.

</Callout>

## 4단계: SAML로 LibreChat 구성하기 [#step-4-configure-librechat-with-saml]

프로젝트 폴더에서 `.env` 파일을 열고 다음 변수들을 추가하세요:

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
