## Adım 1: Auth0 üzerinde bir SAML Uygulaması oluşturun [#step-1-create-a-saml-application-in-auth0]

1. Auth0 Dashboard'unuza giriş yapın.
2. `Applications > Applications` kısmına gidin.
3. `Create Application` öğesine tıklayın.
4. Bir Uygulama Adı girin (örneğin, `LibreChat`) ve `Regular Web Application` seçeneğini seçin.
5. `Create` öğesine tıklayın.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## Adım 2: SAML Eklentisini Yapılandırın [#step-2-configure-the-saml-add-on]

1. Auth0'da yeni oluşturulan uygulamayı açın.
2. `Addons` sekmesine gidin.
3. `SAML2 Web App` özelliğini etkinleştirmek için kaydırıcıya tıklayın.
4. `SAML2 Web App` paneline tıklayın.
5. Aşağıdaki ayarları yapılandırın:
   - **Application Callback URL**: Bunu LibreChat SAML geri çağırma URL'nize ayarlayın:
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **Ayarlar (JSON Formatı)**: Aşağıdaki yapılandırmayı kullanın:
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="Audience, SAML_ISSUER ile eşleşmelidir">
        `audience` değerini, 4. Adımda `SAML_ISSUER` için kullanacağınız dizge ile aynı olacak şekilde ayarlayın.
        Bunu boş bırakırsanız Auth0 kendi varsayılan audience değerini kullanır; bu değer LibreChat'in gönderdiği ile eşleşmeyeceğinden giriş işlemi audience uyuşmazlığı nedeniyle başarısız olur.
        </Callout>
        <Callout type="note" title="not">
        Uygulamanız `given_name`, `family_name`, `username` veya `picture` gibi ek öznitelikler gerektiriyorsa, bu eşlemelerin Auth0 SAML ayarlarında doğru şekilde yapılandırıldığından emin olun.
        </Callout>
6. `Save` düğmesine tıklayın.

## Adım 3: Auth0 SAML Meta Verilerini Edinin [#step-3-obtain-the-auth0-saml-metadata]

1. SAML etkinleştirildikten sonra, `SAML2 Web App` ayarlarına geri dönün.
2. `Usage` sekmesine gidin.
3. `Identity Provider Certificate: Download Auth0 certificate` öğesine tıklayın.
4. `SAML_ENTRY_POINT` için `Identity Provider Login URL` değerini kullanın.
5. `SAML_IDP_ISSUER` için `Issuer` değerini kullanın (isteğe bağlıdır, aşağıdaki uyarıya bakın).
6. İndirilen sertifika dosyasını proje klasörünüze kopyalayın.

<Callout type="warning" title="SAML_ISSUER size aittir, Auth0'ya değil">

`SAML_ISSUER`, **LibreChat'in kimlik doğrulama isteklerinde kendisi hakkında gönderdiği** varlık kimliğidir (entity ID); Auth0'dan kopyaladığınız bir değer değildir. Bunu siz belirlersiniz ve bu değer, Auth0 tarafında **Audience** (Hedef Kitle) olarak girdiğiniz dizge ile aynı olmalıdır. LibreChat temel URL'niz geleneksel seçimdir:

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

Auth0'nun kendi `Issuer` değeri, LibreChat'in bir iddianın gerçekten kimlik sağlayıcınızdan gelip gelmediğini kontrol etmek için kullandığı ayrı `SAML_IDP_ISSUER` değişkenine girilir.

LibreChat bir SAML meta veri belgesi yayınlamaz, bu nedenle Auth0'ya verilecek bir meta veri URL'si yoktur. Auth0'yu yukarıdaki Audience ve aşağıdaki geri çağırma (callback) URL'si ile manuel olarak yapılandırın.

</Callout>

![auth0-4](/images/docs/configuration/authentication/SAML/auth0/4a.png)

## Adım 4: LibreChat'i SAML ile Yapılandırın [#step-4-configure-librechat-with-saml]

Proje klasörünüzdeki `.env` dosyasını açın ve aşağıdaki değişkenleri ekleyin:

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
