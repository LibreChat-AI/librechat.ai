## Étape 1 : Créer une application SAML dans Auth0 [#step-1-create-a-saml-application-in-auth0]

1. Connectez-vous à votre Auth0 Dashboard.
2. Accédez à `Applications > Applications`.
3. Cliquez sur `Create Application`.
4. Saisissez un nom d'application (par ex. `LibreChat`) et sélectionnez `Regular Web Application`.
5. Cliquez sur `Create`.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## Étape 2 : Configurer l'extension SAML [#step-2-configure-the-saml-add-on]

1. Ouvrez l'application nouvellement créée dans Auth0.
2. Allez dans l'onglet `Addons`.
3. Cliquez sur le curseur pour activer la `SAML2 Web App`.
4. Cliquez sur le panneau `SAML2 Web App`.
5. Configurez les paramètres suivants :
   - **URL de rappel de l'application** : Définissez ceci sur votre URL de rappel SAML LibreChat :
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **Paramètres (Format JSON)** : Utilisez la configuration suivante :
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="L'audience doit correspondre à SAML_ISSUER">
        Définissez `audience` avec la même chaîne de caractères que celle que vous utiliserez pour `SAML_ISSUER` à l'étape 4.
        Si vous l'omettez, Auth0 utilisera sa propre audience par défaut, ce qui ne correspondra pas à ce que LibreChat envoie, et la connexion échouera en raison d'une incompatibilité d'audience.
        </Callout>
        <Callout type="note" title="note">
        Si votre application nécessite des attributs supplémentaires tels que `given_name`, `family_name`, `username` ou `picture`, assurez-vous que ces mappages sont correctement configurés dans les paramètres SAML de Auth0.
        </Callout>
6. Cliquez sur `Save`.

## Étape 3 : Obtenir les métadonnées SAML d'Auth0 [#step-3-obtain-the-auth0-saml-metadata]

1. Une fois SAML activé, retournez dans les paramètres de la `SAML2 Web App`.
2. Allez dans l'onglet `Usage`.
3. Cliquez sur `Identity Provider Certificate: Download Auth0 certificate`.
4. Utilisez l'`Identity Provider Login URL` pour `SAML_ENTRY_POINT`.
5. Utilisez l'`Issuer` pour `SAML_IDP_ISSUER` (optionnel, voir l'encadré ci-dessous).
6. Copiez le fichier de certificat téléchargé dans votre dossier de projet.

<Callout type="warning" title="SAML_ISSUER est le vôtre, pas celui d'Auth0">

`SAML_ISSUER` est l'ID d'entité que **LibreChat envoie à son propre sujet** dans ses requêtes d'authentification, et non une valeur que vous copiez depuis Auth0. Vous le choisissez, et il s'agit de la même chaîne que celle que vous saisissez du côté d'Auth0 en tant qu'**Audience**. Votre URL de base LibreChat est le choix conventionnel :

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

La valeur `Issuer` propre à Auth0 doit être placée dans la variable distincte `SAML_IDP_ISSUER`, que LibreChat utilise pour vérifier qu'une assertion provient réellement de votre fournisseur d'identité.

LibreChat ne publie pas de document de métadonnées SAML, il n'y a donc pas d'URL de métadonnées à fournir à Auth0. Configurez Auth0 manuellement avec l'Audience ci-dessus et l'URL de rappel ci-dessous.

</Callout>

## Étape 4 : Configurer LibreChat avec SAML [#step-4-configure-librechat-with-saml]

Ouvrez le fichier `.env` dans votre dossier de projet et ajoutez les variables suivantes :

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
