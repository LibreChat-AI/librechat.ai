## Bước 1: Tạo một ứng dụng SAML trong Auth0 [#step-1-create-a-saml-application-in-auth0]

1. Đăng nhập vào Auth0 Dashboard của bạn.
2. Điều hướng đến `Applications > Applications`.
3. Nhấp vào `Create Application`.
4. Nhập Tên Ứng dụng (ví dụ: `LibreChat`) và chọn `Regular Web Application`.
5. Nhấp vào `Create`.

![auth0-1](/images/docs/configuration/authentication/SAML/auth0/1.png)


## Bước 2: Cấu hình SAML Add-On [#step-2-configure-the-saml-add-on]

1. Mở ứng dụng vừa tạo trong Auth0.
2. Đi tới tab `Addons`.
3. Nhấp vào thanh trượt để bật `SAML2 Web App`.
4. Nhấp vào bảng `SAML2 Web App`.
5. Cấu hình các cài đặt sau:
   - **Application Callback URL**: Thiết lập giá trị này thành URL callback SAML của LibreChat:
   `https://YOUR_DOMAIN/oauth/saml/callback`
   - **Cài đặt (Định dạng JSON)**: Sử dụng cấu hình sau:
        ```json
        {
            "audience": "https://your-librechat-domain.com",
            "mappings": {
                "email": "email",
                "name": "username"
            }
        }
        ```
        <Callout type="warning" title="Audience phải khớp với SAML_ISSUER">
        Đặt `audience` thành cùng một chuỗi mà bạn sẽ sử dụng cho `SAML_ISSUER` trong Bước 4.
        Nếu bỏ qua, Auth0 sẽ xác nhận audience mặc định của riêng nó, điều này sẽ không khớp với những gì LibreChat gửi, và quá trình đăng nhập sẽ thất bại do lỗi không khớp audience.
        </Callout>
        <Callout type="note" title="lưu ý">
        Nếu ứng dụng của bạn yêu cầu các thuộc tính bổ sung như `given_name`, `family_name`, `username` hoặc `picture`, hãy đảm bảo rằng các ánh xạ này được cấu hình đúng trong cài đặt SAML của Auth0.
        </Callout>
6. Nhấp vào `Save`.

## Bước 3: Lấy Metadata SAML của Auth0 [#step-3-obtain-the-auth0-saml-metadata]

1. Sau khi SAML đã được bật, hãy quay lại cài đặt `SAML2 Web App`.
2. Đi tới tab `Usage`.
3. Nhấp vào `Identity Provider Certificate: Download Auth0 certificate`.
4. Sử dụng `Identity Provider Login URL` cho `SAML_ENTRY_POINT`.
5. Sử dụng `Issuer` cho `SAML_IDP_ISSUER` (tùy chọn, xem phần lưu ý bên dưới).
6. Sao chép tệp chứng chỉ đã tải xuống vào thư mục dự án của bạn.

<Callout type="warning" title="SAML_ISSUER là của bạn, không phải của Auth0">

`SAML_ISSUER` là ID thực thể mà **LibreChat gửi về chính nó** trong các yêu cầu xác thực, không phải là giá trị bạn sao chép từ Auth0. Bạn tự chọn giá trị này và nó phải là cùng một chuỗi mà bạn nhập ở phía Auth0 trong phần **Audience**. URL cơ sở của LibreChat là lựa chọn thông thường:

```bash filename=".env"
SAML_ISSUER=https://your-librechat-domain.com
```

Giá trị `Issuer` của riêng Auth0 sẽ nằm trong biến `SAML_IDP_ISSUER` riêng biệt, được LibreChat sử dụng để kiểm tra xem xác nhận (assertion) có thực sự đến từ nhà cung cấp danh tính của bạn hay không.

LibreChat không xuất bản tài liệu siêu dữ liệu SAML, vì vậy không có URL siêu dữ liệu nào để cung cấp cho Auth0. Hãy cấu hình Auth0 thủ công với Audience ở trên và URL callback ở dưới đây.

</Callout>

## Bước 4: Cấu hình LibreChat với SAML [#step-4-configure-librechat-with-saml]

Mở tệp `.env` trong thư mục dự án của bạn và thêm các biến sau:

  ```bash filename=".env"
  SAML_ENTRY_POINT=https://dev-xxxxx.us.auth0.com/samlp/aaaaaa

  # Your own entity ID, sent to Auth0. Must match the Audience you set in Auth0.
  SAML_ISSUER=https://your-librechat-domain.com
  # Auth0's Issuer, used to verify incoming assertions (optional)
  SAML_IDP_ISSUER=urn:dev-xxxxx.us.auth0.com

  SAML_CERT=dev-xxxxx.pem
  SAML_CALLBACK_URL=/oauth/saml/callback
  SAML_SESSION_SECRET=[JustGenerateARandomSessionSecret]

  # Attribute mappings (optional)
  SAML_EMAIL_CLAIM=
  SAML_USERNAME_CLAIM=
  SAML_GIVEN_NAME_CLAIM=
  SAML_FAMILY_NAME_CLAIM=
  SAML_PICTURE_CLAIM=
  SAML_NAME_CLAIM=

  # Login button settings (optional)
  SAML_BUTTON_LABEL=
  SAML_IMAGE_URL=

  # Whether the SAML Response should be signed.
  # - If "true", the entire `SAML Response` will be signed.
  # - If "false" or unset, only the `SAML Assertion` will be signed (default behavior).
  # SAML_USE_AUTHN_RESPONSE_SIGNED=
  ```
