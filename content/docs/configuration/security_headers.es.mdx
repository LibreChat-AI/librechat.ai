LibreChat envía un conjunto base de encabezados de seguridad HTTP en cada respuesta, incluyendo los endpoints de salud. Una política de seguridad de contenido (CSP) basada en nonce está disponible por separado y está desactivada de forma predeterminada para que las integraciones existentes puedan ser auditadas antes de su aplicación.

## Encabezados de referencia [#baseline-headers]

Los encabezados base están habilitados a menos que `SECURITY_HEADERS=false`. Esa variable es el interruptor global: deshabilita tanto los encabezados base como la CSP.

| Variable | Default | Behavior |
| --- | --- | --- |
| `SECURITY_HEADERS` | `true` | Habilita todos los encabezados base. `false` también deshabilita CSP. |
| `HSTS_ENABLED` | `true` | Envía `Strict-Transport-Security`. Los navegadores solo lo respetan a través de HTTPS. |
| `HSTS_MAX_AGE` | `31536000` | Tiempo de vida de HSTS en segundos. Debe ser un número entero no negativo. |
| `HSTS_INCLUDE_SUBDOMAINS` | `false` | Aplica HSTS a todos los subdominios. Habilítelo solo cuando todos los subdominios usen HTTPS. |
| `HSTS_PRELOAD` | `false` | Agrega el token `preload` de HSTS. |
| `X_FRAME_OPTIONS` | `SAMEORIGIN` | Acepta `SAMEORIGIN`, `DENY` o `off`. |
| `REFERRER_POLICY` | `no-referrer` | Establece `Referrer-Policy`; use `off` para omitirlo. |
| `CROSS_ORIGIN_OPENER_POLICY` | `same-origin` | Establece `Cross-Origin-Opener-Policy`; use `off` para omitirlo. |
| `CROSS_ORIGIN_RESOURCE_POLICY` | `same-origin` | Establece `Cross-Origin-Resource-Policy`; use `off` para omitirlo. |

Helmet también envía `X-Content-Type-Options: nosniff`. Los valores no válidos se registran y se recurre a los valores predeterminados documentados.

Las políticas de apertura aceptadas son `same-origin`, `same-origin-allow-popups`, `noopener-allow-popups` y `unsafe-none`. Las políticas de recursos aceptadas son `same-origin`, `same-site` y `cross-origin`. Las políticas de referencia aceptadas son `no-referrer`, `no-referrer-when-downgrade`, `same-origin`, `origin`, `strict-origin`, `origin-when-cross-origin`, `strict-origin-when-cross-origin` y `unsafe-url`.

```bash filename=".env"
SECURITY_HEADERS=true
HSTS_ENABLED=true
HSTS_MAX_AGE=31536000
HSTS_INCLUDE_SUBDOMAINS=false
HSTS_PRELOAD=false
X_FRAME_OPTIONS=SAMEORIGIN
REFERRER_POLICY=no-referrer
CROSS_ORIGIN_OPENER_POLICY=same-origin
CROSS_ORIGIN_RESOURCE_POLICY=same-origin
```

Si un proxy ascendente también escribe estas cabeceras, mantenga una política autoritativa y verifique la respuesta final vista por el navegador.

## Content Security Policy [#content-security-policy]

CSP es opcional (opt-in). LibreChat crea un nonce nuevo para cada respuesta de SPA y lo aplica a los scripts ejecutables y a los enlaces de precarga de módulos (module-preload) en el shell.

<Callout type="warning" title="Iniciar en modo de solo informe">
  Habilite CSP con `CSP_REPORT_ONLY=true`, recopile las violaciones de su despliegue real, añada solo las fuentes requeridas y aplique la restricción solo después de que los flujos de la aplicación, autenticación, almacenamiento, telemetría y contenido incrustado estén limpios.
</Callout>

```bash filename=".env"
CSP_ENABLED=true
CSP_REPORT_ONLY=true
CSP_REPORT_URI=https://reports.example.com/csp

# Examples for deployment-specific services
CSP_CONNECT_SRC_EXTRA="https://telemetry.example.com wss://stream.example.com"
CSP_FRAME_SRC_EXTRA=https://tenant.sharepoint.com
CSP_IMG_SRC_EXTRA=https://cdn.example.com
```

`CSP_REPORT_ONLY` tiene como valor predeterminado `true`. Solo un valor falso reconocido cambia a la aplicación forzosa; un valor no reconocido se registra y permanece en modo de solo informe. Mientras CSP está habilitado, LibreChat fuerza al shell de la SPA a `Cache-Control: no-store` e ignora `INDEX_CACHE_CONTROL`, `INDEX_PRAGMA` e `INDEX_EXPIRES` para esa respuesta, de modo que un nonce no pueda reutilizarse desde la caché.

### Variables CSP [#csp-variables]

| Variable | Default | Behavior |
| --- | --- | --- |
| `CSP_ENABLED` | `false` | Habilita CSP basado en nonce para el shell de la SPA. |
| `CSP_REPORT_ONLY` | `true` | Envía `Content-Security-Policy-Report-Only`; establézcalo en `false` para aplicar la política. |
| `CSP_REPORT_URI` | vacío | Añade la directiva heredada `report-uri`. |
| `CSP_ALLOW_WASM` | `true` | Permite la compilación de WebAssembly utilizada por la conversión HEIC. |
| `CSP_ALLOW_DATA_WORKERS` | `true` | Permite workers `data:` utilizados por el cargador de Monaco. |
| `CSP_FRAME_ANCESTORS` | `'self'` | Reemplaza la lista completa de fuentes `frame-ancestors`. |
| `CSP_ADDITIONAL_DIRECTIVES` | vacío | Añade directivas sin procesar separadas por punto y coma. |

Estas variables añaden fuentes a la directiva integrada correspondiente:

- `CSP_DEFAULT_SRC_EXTRA`
- `CSP_SCRIPT_SRC_EXTRA`
- `CSP_STYLE_SRC_EXTRA`
- `CSP_IMG_SRC_EXTRA`
- `CSP_FONT_SRC_EXTRA`
- `CSP_CONNECT_SRC_EXTRA`
- `CSP_MEDIA_SRC_EXTRA`
- `CSP_FRAME_SRC_EXTRA`
- `CSP_WORKER_SRC_EXTRA`
- `CSP_FORM_ACTION_EXTRA`

Las listas de fuentes pueden estar separadas por comas o espacios. Estas se añaden en lugar de reemplazar los valores predeterminados de LibreChat. `CSP_FRAME_ANCESTORS` es la excepción, ya que reemplaza intencionalmente el valor predeterminado `'self'`.

La política de script predeterminada utiliza `'strict-dynamic'`. Configurar `CSP_SCRIPT_SRC_EXTRA` elimina `'strict-dynamic'` para que los hosts de script listados puedan surtir efecto. Liste únicamente los orígenes en los que confía para ejecutar código en LibreChat.

Si otro origen debe incluir a LibreChat, aplique `frame-ancestors` antes de eliminar `X-Frame-Options`:

```bash filename=".env"
CSP_ENABLED=true
CSP_REPORT_ONLY=false
X_FRAME_OPTIONS=off
CSP_FRAME_ANCESTORS="'self' https://portal.example.com"
```

No establezca `X_FRAME_OPTIONS=off` mientras CSP esté deshabilitado o en modo de solo informe (report-only). Una política de solo informe registra las infracciones pero no restringe el enmarcado (framing), por lo que eliminar `X-Frame-Options` primero permitiría que cualquier origen enmarque el despliegue. Los navegadores sin soporte para `frame-ancestors` no aplicarán una restricción de enmarcado en esta configuración de origen cruzado.

Consulte la [referencia de variables de entorno](/docs/configuration/dotenv#security-headers-and-content-security-policy) para saber dónde se encuentran estos ajustes en `.env`.
